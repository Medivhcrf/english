一、名词后缀（最容易混的一组 · 先看这里）

一句话总结：-ness = "感觉/状态"，-ment = "动作的产物"，-tion = "动作本身/结果"，-ity = "品质/性质"，-ance/-ence = "动作的状态"，-ship = "身份/关系"，-hood = "人生阶段/群体"，-dom = "领域/统治"，-age = "行为/总量"。同源词根的动词会告诉你该用哪个。
后缀核心意思典型词vs 其他
-ness 状态、感觉（日耳曼，加形容词） happiness 快乐、kindness 善良、darkness 黑暗、awareness 意识 最万能，几乎任何形容词都能加；表"感觉到的状态"
-ment 行为的产物、结果（拉丁，加动词） development 发展、agreement 协议、improvement 改进、achievement 成就 强调"做出来的东西/结果"，不是感觉
-tion 行为、动作本身（拉丁，加动词） information 信息、education 教育、decision 决定、creation 创造 表"这个动作"本身；-ment 表"动作的结果"，两者最易混
-ity / -ty 性质、品质（拉丁，加形容词） ability 能力、reality 现实、activity 活动、diversity 多样性 vs -ness：-ness 表"感觉到状态"，-ity 表"客观属性"；ability 不说 ableness
-ance / -ence 动作的状态（拉丁，配 -ant/-ent 形容词） importance 重要性、performance 表现、patience 耐心、difference 差别 见 -ant/-ent 形容词，名词就配 -ance/-ence；如 important→importance
-ship 身份、关系（日耳曼） friendship 友谊、leadership 领导、membership 会员、scholarship 奖学金 表"人与人的关系 / 身份地位"
-hood 人生阶段、群体（日耳曼） childhood 童年、neighborhood 社区、brotherhood 兄弟情 表"一段人生 / 一类人组成的群体"
-dom 领域、统治状态（日耳曼） kingdom 王国、freedom 自由、wisdom 智慧、boredom 无聊 表"统辖的领域"或"抽象境界"
-age 行为、总量（拉丁/法语） usage 用法、storage 存储、package 包裹、luggage 行李、postage 邮资 表"行为本身"或"东西的集合量"
记忆口诀：感觉靠 ness，结果靠 ment，动作靠 tion，属性靠 ity，关系靠 ship，阶段靠 hood，领域靠 dom，总量靠 age。 想不起来就看原动词：develop（发展）→development，educate（教育）→education，happy（开心）→happiness，able（有能力）→ability。

二、"人"后缀

后缀含义典型词辨析
-er / -or 做…的人/物（日耳曼/拉丁） teacher 老师、worker 工人、actor 演员、doctor 医生 最通用；-er 日耳曼，-or 拉丁
-ist 专业人员/主义者（希腊） artist 艺术家、scientist 科学家、dentist 牙医 表"以…为业 / 信仰…的人"
-ant / -ent 做…的人（拉丁分词） assistant 助手、student 学生、president 总统 见形容词 -ant/-ent，常成对
-ee 被…的人（法语） employee 雇员、trainee 学员、payee 收款人 与 -er 成对：employer 雇主 / employee 雇员
-ess 女性（法语，渐少用） actress 女演员、princess 公主、waitress 女服务生 现代趋向中性化（用 server 而非 waitress）

三、形容词后缀

后缀含义典型词辨析
-ful 充满…的（日耳曼） careful 仔细的、hopeful 充满希望的、beautiful 美丽的 "满"→褒义居多
-less 无…的（日耳曼） careless 粗心的、helpless 无助的、useless 无用的 -ful 的反面：careful 细心 / careless 粗心
-able / -ible 可…的（拉丁） comfortable 舒服的、reliable 可靠的、possible 可能的 加动词表"能被…的"：read→readable 可读
-ous 充满…的、具…性质（拉丁） dangerous 危险的、famous 著名的、nervous 紧张的 vs -ful：-ous 多表"带来…的"（dangerous 带来危险）
-al 与…有关的（拉丁） natural 自然的、personal 个人的、cultural 文化的 中性"归属/相关"
-ive 倾向于…的、有…能力（拉丁） active 积极的、creative 有创造力的、decisive 果断的 强调"爱做… / 能做…"
-ly …的 / …地（日耳曼） friendly 友好的（形）、quickly 快速地（副） 加名词变形容词（friendly），加形容词变副词（quickly）

四、动词后缀

后缀含义典型词辨析
-ize / -ise 使…化、变成（希腊） realize 意识到、modernize 现代化、organize 组织 美式 -ize，英式 -ise 通用
-ify 使…（拉丁） clarify 澄清、magnify 放大、beautify 美化 与 -ize 近似，-ify 更短促（未单独成篇，见词根卡片）

五、否定前缀（dis-/un-/non-/in-/mis-/de-）

前缀含义典型词辨析
un- 单纯否定状态（日耳曼） unhappy 不开心、unclear 不清楚、unfair 不公平 最常用，"没有这种状态"
dis- 主动反向动作（拉丁） disagree 不同意、disconnect 断开、disappear 消失 强调"去做相反的事"
non- 客观分类"非"（拉丁） nonstop 不停的、nonfiction 纪实、nonprofit 非营利 表"不属于某类"，最中性
in- / il- / im- / ir- 形容词否定（拉丁） illegal 非法、impossible 不可能、irregular 不规则 后面首字母同化（l→il、p/m→im、r→ir）
mis- 做错了（日耳曼） mistake 错误、misunderstand 误解、mislead 误导 强调"方式不对、搞错"
de- 向下/离开/反转（拉丁） decrease 减少、decode 解码、depart 出发 "向下"或"反过来"
记法：没状态用 un（unhappy），反着做用 dis（disagree），归类别用 non（nonfiction），形容词否定用 in（impossible），搞错了用 mis（mistake），往下/反着用 de（decode）。

前缀含义典型词

pre-时间上"预先"prepare 准备、predict 预测
post-时间上"之后"postpone 推迟、postwar 战后
fore-位置"在前"（日耳曼）forecast 预报、foresee 预见
inter-在…之间international 国际的、interview 面试
trans-横跨transport 运输、translate 翻译
ex- / e-向外exit 出口、export 出口
out-向外（日耳曼）output 产出、outstanding 杰出
over-过度、在上overwork 加班、overdue 逾期
super- / sur-超越、在上supermarket 超市、survive 幸存
sub-在下subway 地铁、submit 提交
under-在下（日耳曼）underground 地下、understand 理解
per-贯穿、彻底perfect 完美、persist 坚持
intro- / intra-向内 / 内部introduce 介绍、introvert 内向
circum-环绕circumstance 情况、circumference 周长
anti-对抗（希腊）antibiotic 抗生素、antisocial 反社会
syn- / sym-一起（希腊）symphony 交响乐、system 系统
com- / con- / co-一起（拉丁）combine 结合、cooperate 合作
时间对：pre-（之前）↔ post-（之后）｜ 位置对：fore-（在前）↔ after ｜ 方向对：inter-（之间）↔ intra-（内部）↔ intro-（向内）｜ 上下对：super-/over-（上）↔ sub-/under-（下）｜ 内外对：ex-/out-（外）↔ in-（内）
