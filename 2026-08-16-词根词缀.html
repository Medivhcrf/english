词根（7 个）

1clar = clear 清晰、明亮
💡 记法：clarify = 让事情变"清晰"；declare = 大声说"清楚"（宣布） 词源：拉丁语 clarus「清晰的、明亮的」，源自印欧语 *kelh₁-「喊、响」（喊得响亮→清晰） 演化：清晰 → 使清晰=clarify ｜ 说清楚=declare ｜ 清晰度=clarity
  • clear 清楚的、晴朗的 （clar 的法语变体）
  • clarify 澄清、阐明 （clar + -ify 使清晰）
  • declare 宣布 （de- 完全 + clar + -e，"大声说清楚"）
  • declaration 宣言 （declarat + -ion）
  • clarity 清晰度 （clar + -ity）
  • clarinet 单簧管 （clar + -inet，"音色清亮的乐器"）
口语/生活用：Can you clarify what you meant by that? 你能说明一下你那么说的意思吗？
2fid = faith, trust 信任
💡 记法：confident = 对自"信"的；confide = 把秘密托付给信任的人 词源：拉丁语 fidere「信任」、fides「信念」，源自印欧语 *bheidh-「信任」 演化：信任 → 自信=confident ｜ 交托=confide ｜ 忠实=fidelity
  • confident 自信的 （con- 加强 + fid + -ent，"全然信任自己"）
  • confide 吐露秘密 （con- + fide，"把心事交托出去"）
  • fidelity 忠诚 （fid + -elity，"守信的品质"）
  • faithful 忠实的 （faith 同源 + -ful）
  • infidel 异教徒 （in- 不 + fid + -el，"无信仰者"）
  • fiduciary 受托的、信托的 （fid + -uciary，"受人信任托付"）
口语/生活用：I'm confident that we'll win the match. 我有信心我们能赢得这场比赛。
3loc = place 地方
💡 记法：location = "地方"；local = 当地的（本地这个"地方"的） 词源：拉丁语 locus「地方」 演化：地方 → 定位=locate ｜ 分到各处=allocate ｜ 换地方=relocate
  • local 当地的 （loc + -al，"这一处的"）
  • locate 定位 （loc + -ate，"确定所在之处"）
  • location 位置 （locat + -ion）
  • allocate 分配 （al- 朝 + loc + -ate，"把…分到各处"）
  • relocate 搬迁 （re- 再 + locate，"换地方"）
  • locomotive 火车头 （loco + mot 移动，"带动换地方之物"）
口语/生活用：Let's relocate the meeting to the conference room. 我们把会议改到会议室吧。
4not = mark 标记、记号
💡 记法：note = 做"标记"（笔记、音符）；notice = 注意到"标记" 词源：拉丁语 nota「记号」、notare「做标记」 演化：标记 → 记下=note ｜ 注意到=notice ｜ 显著的=notable ｜ 通知=notify
  • note 笔记、音符 （not + -e，记下的符号）
  • notice 注意到、通知 （not + -ice，"看到标记"）
  • notable 显著的 （not + -able，"值得做标记的"）
  • notify 通知 （not + -ify，"做标记告知"）
  • notation 记号法 （not + -ation，数学/音乐符号）
  • notorious 臭名昭著的 （not + -orious，"众所周知（坏事）"）
口语/生活用：I noticed you've been quiet all morning — is everything okay? 我注意到你整个上午都很安静——一切都好吗？
5punct = point 点、刺
💡 记法：punctual = 卡在"点"上（准时）；puncture = 刺出"点"（刺破） 词源：拉丁语 punctum「点」，pungere「刺」，源自印欧语 *peuk-「刺」 演化：点/刺 → 准点=punctual ｜ 标点=punctuation ｜ 刺穿=puncture
  • punctual 准时的 （punct + -ual，"正好在点上"）
  • punctuation 标点符号 （punct + -uation，"句子里的点"）
  • punctuality 守时 （punctual + -ity）
  • puncture 刺破、穿刺 （punct + -ure）
  • acupuncture 针灸 （acu 针 + puncture，"针刺"）
  • compunction 内疚 （com- + punct + -ion，"良心被刺到"）
口语/生活用：Please be punctual — the train leaves at nine sharp. 请务必准时——火车九点整发车。
6dynam = power 力量（希腊）
💡 记法：dynamic = 有"力量"的（有活力的）；dynamite = 炸药（爆发力） 词源：希腊语 dynamis「力量」，dynasthai「有能力」 演化：力量 → 有活力的=dynamic ｜ 炸药=dynamite ｜ 掌权世系=dynasty
  • dynamic 动态的、有活力的 （dynam + -ic）
  • dynamite 炸药 （dynam + -ite，"有爆发力之物"）
  • dynasty 王朝 （dynam + -y，"掌权者的世系"）
  • dynamo 发电机 （dynam + -o，"产生力量之物"）
  • thermodynamics 热力学 （therm 热 + dynam + -ics）
  • aerodynamic 空气动力学的 （aero 空气 + dynamic）
口语/生活用：She's a dynamic speaker who energizes the whole room. 她是一位充满活力的演讲者，能带动全场气氛。
7techn = skill 技艺、技术（希腊）
💡 记法：technology = 关于"技艺"的学问；technique = 技巧 词源：希腊语 techne「技艺、手艺」 演化：技艺 → 技术=technology ｜ 技巧=technique ｜ 技术上的=technical
  • technology 科技 （techn + -ology 学问）
  • technique 技巧 （techn + -ique，法语）
  • technical 技术的 （techn + -ical）
  • technician 技术员 （techn + -ician 人）
  • architect 建筑师 （archi 主 + tect，"建造技艺的统领者"）
  • polytechnic 理工学院 （poly 多 + techn + -ic，"多科技艺"）
口语/生活用：New technology changes the way we live every few years. 新技术每隔几年就改变一次我们的生活方式。

词缀（3 个）

8-ee = receiver 被…的人（法语）
💡 记法：employee = 被雇的"人"；trainee = 正在受训的"人" 词源：法语 -é（过去分词），借入英语表"动作的接受者"，与施动者后缀 -er/-or 相对 演化：法语 -é → 英语 -ee，"被…的人"
  • employee 雇员 （employ + -ee，被雇佣者）
  • trainee 受训者 （train + -ee）
  • payee 收款人 （pay + -ee，被付款者）
  • interviewee 被面试者 （interview + -ee）
  • refugee 难民 （refuge + -ee，"寻求庇护者"）
  • addressee 收信人 （address + -ee，"被寄信者"）
💡 深度辨析：-ee vs -er/-or -ee（动作接受者）：employee, trainee, payee
-er / -or（动作施动者，Day 5）：employer, teacher, actor
成对记忆：employer（雇主）vs employee（雇员）｜ interviewer（面试官）vs interviewee（求职者）
口语/生活用：All employees must attend the safety training. 所有员工都必须参加安全培训。
9circum- = around 环绕（拉丁）
💡 记法：circumference = 围绕"一圈"的长度（周长）；circumstance = 周围站着的"情况" 词源：拉丁语 circum「周围」，源自 circus（圆形）+ um 演化：环绕 → 周长=circumference ｜ 环境=circumstance ｜ 绕开=circumvent
  • circumference 周长 （circum- + fer 携带，"绕一圈的长度"）
  • circumstance 情况、环境 （circum- + st 站立，"周围站着的情况"）
  • circumspect 谨慎的 （circum- + spect 看，"环顾四周"）
  • circumnavigate 环球航行 （circum- + navigate 航行）
  • circumvent 绕开、规避 （circum- + vent 来，"绕着走避开"）
  • circumscribe 限制 （circum- + scribe 画，"在周围画圈限制"）
口语/生活用：Under the circumstances, we'd better cancel the trip. 在这种情况下，我们最好取消行程。
10fore- = before 在前、预先（古英语）
💡 记法：forecast = 预先"抛"出的判断（预报）；forehead = "前"额 词源：古英语 fore「在前」，源自印欧语 *per-「向前」；与拉丁 pre-、希腊 pro- 同源 演化：在前 → 预知=forecast ｜ 先见=foresight ｜ 预先警告=forewarn
  • forecast 预报 （fore- + cast 抛，"预先抛出的判断"）
  • forehead 额头 （fore- + head，"头部前方"）
  • foresee 预见 （fore- + see）
  • foresight 远见 （fore- + sight 视）
  • forearm 前臂 （fore- + arm）
  • forewarn 预先警告 （fore- + warn）
💡 深度辨析：fore- / pre- / pro- fore-（日耳曼，"在前"）：forecast, foresee
pre-（拉丁，"预先"，Day 2）：prepare, predict
pro-（拉丁/希腊，"向前+支持"，Day 9）：progress, promote
三者同出 PIE *per-，只是各自经不同语言进入英语
口语/生活用：The forecast says rain tomorrow, so bring an umbrella. 预报说明天下雨，带把伞吧。
