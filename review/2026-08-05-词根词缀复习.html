词根词缀复习 · 覆盖 Day 1–2

2026 年 8 月 5 日 ｜ 覆盖 2 天 · 词根 14 个 · 词缀 6 个 ｜ 单词 105 个 · 例句 20 句 ｜ 复习 · 查漏补缺

一、知识清单回顾

Day 1 ｜ 2026 年 8 月 4 日（1 天前） ｜ 词根 7 个 · 词缀 3 个
1spect = 看（look）
expect 期待，预料 （向外看 → 望向未来） ・ respect 尊重 （反复看 → 仰视） ・ suspect 怀疑；嫌疑犯 （向下看 → 心里犯嘀咕） ・ inspect 检查，视察 （往里看） ・ spectator 观众
向前看 → expect 期待 ｜ 反复看 → respect 尊重 ｜ 向下看 → suspect 怀疑 ｜ 往里看 → inspect 检查
口语：I expect you to be on time. 我希望你准时到。
2port = 搬运（carry）
report 报告 （搬回来 → 汇报） ・ support 支持 （从下面托着） ・ transport 运输 （从这里搬到那里） ・ import / export 进口 / 出口 ・ portable 便携的
搬回 → report 报告 ｜ 从下面托住 → support 支持 ｜ 搬到别处 → transport 运输 ｜ 带进去/带出去 → import / export
生活用：portable charger 充电宝
3dict = 说（say）
predict 预测 （提前说） ・ dictionary 词典 （说出来的词） ・ dictate 口述；支配 （"我说了算"） ・ contradict 反驳 （对着说）
提前说 → predict 预测 ｜ 对着说 → contradict 反驳 ｜ 一遍遍说 → dictate 口述、支配
口语：Don't dictate to me. 别对我指手画脚。
4cred = 相信（believe）
credit 信用；学分；贷款 ・ incredible 难以置信的 （口语里 = 超赞） ・ credible 可信的 ・ credentials 学历 / 资质证明
交心 → 信任 → credit 信用 ｜ 加 in-（不）→ incredible 难以置信 ｜ 加 -ible → credible 可信的
生活用：credit card 信用卡（几乎天天见）
5vis / vid = 看（see）
visit 参观，拜访 ・ visible 看得见的 ・ vision 视力；愿景 ・ revise 复习；修改 （再看一遍） ・ evidence 证据 （看得见的事实）
再看一遍 → revise 复习 ｜ 看得见 → visible ｜ 看得见的事实 → evidence 证据
词组：revise for the exam 复习备考
6tele = 远（far）
telephone 电话 （远方传来的声音） ・ television 电视 ・ telescope 望远镜 ・ telework / telecommute 远程办公 ・ telemedicine 远程医疗
19 世纪起科学新词大量用它构词：远+声 → telephone 电话 ｜ 远+视 → television 电视 ｜ 远+看 → telescope 望远镜；现代又造出 telework、telemedicine
生活用：现在很多人：work from home （在家办公）
7bio = 生命（life）
biology 生物学 ・ biography 传记 （写一生） ・ biodegradable 可生物降解的 ・ biofuel 生物燃料
17–19 世纪出现 biology 生物学、biography 传记 → 20 世纪造出 biofuel、biodegradable；如今 bio- 成了环保标识的常见前缀
生活用：biodegradable plastic 可降解塑料（超市购物袋上常见）
8re- = 再、又、回（again / back）
return 返回；归还 ・ review 复习；评论 （再看一遍） ・ recycle 回收利用 ・ refund 退款 （把钱退回来）
转回去 → return 返回、refund 退款 ｜ 转回起点 → recycle 回收、reuse 再利用 ｜ 再看一遍 → review 复习
生活用：I'd like a refund. 我要退款。—— 购物退换货最常用的一句！
9-able / -ible = 可…的（able to be）
comfortable 舒服的 ・ available 有空的；可获得的 ・ reliable 可靠的 ・ affordable 买得起的
最初只接拉丁语动词（visible、credible）→ 后来"本土化"可接任何动词：washable、breakable——构词能力极强
口语：Are you available tomorrow? 你明天有空吗？—— 几乎天天用
10-less = 无…的（without）
helpless 无助的 ・ careless 粗心的 ・ useless 没用的 ・ wireless 无线的 ・ endless 无尽的
古英语时期就开始大量构词（homeless 早在 12 世纪）→ 现代无线时代又造出 wireless
生活用：wireless charging 无线充电
Day 2 ｜ 2026 年 8 月 5 日（0 天前） ｜ 词根 7 个 · 词缀 3 个
1fac / fact / fect = do, make（做，制作）【拉丁】
fact 事实；真相 （factum 做出来的事 → 已成事实） ・ factory 工厂 （fact 做 + -ory 场所 → 制作东西的地方） ・ manufacture 制造，生产 （manu 手 + fact 做 + -ure → 手工制作→工厂生产） ・ affect 影响；使感动 （af- 朝向 + fect 做 → 作用于） ・ effect 效果，影响 （ef- 出 + fect 做 → 做出来的结果） ・ perfect 完美的 （per- 完全 + fect 做 → 做得完满）
本义「做」 → factor 做的人/因素、manufacture 亲手制作 ｜ 「做出来的东西」 → fact 事实、factory 工厂、effect 效果 ｜ 「外力作用于」 → affect 影响 ｜ 「完全做好」 → perfect 完美
口语/生活用：The factory manufactures thousands of phones a day. 这家工厂每天生产数千部手机。
2scrib / script = write（写）【拉丁】
describe 描述 （de- 向下 + scribe 写 → 把所见写下来） ・ subscribe 订阅；赞同 （sub- 在下面 + scribe 写 → 在文件下方署名→订阅） ・ manuscript 手稿；原稿 （manu 手 + script 写 → 手写的稿子） ・ prescribe 开处方；规定 （pre- 预先 + scribe 写 → 预先写好的医嘱） ・ transcript 成绩单；文字记录 （trans- 转 + script → 转写下来的记录） ・ script 剧本；脚本 （刻写的内容 → 写好的台本）
本义「刻写」 → describe 描下来=描述、transcript 转写 ｜ 「预先写(处方)」 → prescribe 开处方 ｜ 「在下面签名」 → subscribe 订阅、签字同意
口语/生活用：I subscribed to the streaming service to watch the new show. 我订阅了流媒体服务来追那部新剧。
3mit / miss = send, let go（送，放出）【拉丁】
mission 使命；任务 （miss 送 + -ion → 被派送出去的差事） ・ transmit 传送；发射 （trans- 穿过 + mit → 送过去） ・ submit 提交；屈服 （sub- 从下 + mit → 送上去；甘拜下风） ・ admit 承认；准许进入 （ad- 向里 + mit → 放进→允许） ・ dismiss 解散；不予理会 （dis- 分开 + miss → 打发走） ・ permission 许可 （per- 通过 + miss + -ion → 放行）
本义「送」 → transmit 传送、emit 发出 ｜ 「被送出去的任务」 → mission 使命 ｜ 「把…送走」 → dismiss 解散 ｜ 「放进来」 → admit 承认/准入
口语/生活用：You have to submit your assignment before midnight. 你必须在午夜前提交作业。
4struct = build（建造）【拉丁】
construct 建造；构建 （con- 一起 + struct → 搭到一起） ・ structure 结构；建筑物 （struct + -ure → 搭出来的东西） ・ instruct 教导；指示 （in- 往里 + struct → 往里搭知识） ・ destroy 摧毁 （de- 拆除 + stroy/struct → 拆掉搭建物） ・ obstruct 妨碍，阻挡 （ob- 迎面 + struct → 挡在前面） ・ infrastructure 基础设施 （infra- 下面 + structure → 下面的建造）
本义「堆叠建造」 → construct 一起搭建、structure 结构 ｜ 「往头脑里搭建」 → instruct 教导 ｜ 「拆掉搭建」 → destroy 摧毁 ｜ 「挡住建造」 → obstruct 妨碍
口语/生活用：They're constructing a new subway line near my place. 他们正在我家附近修一条新地铁线。
5voc / vok = call, voice（喊，声音）【拉丁】
vocal 嗓音的；直言不讳的 （voc 声音 + -al 形容词） ・ vocabulary 词汇；词汇量 （vocabulum 词 + -ary → 喊出来的词的总和） ・ advocate 提倡者；辩护 （ad- 朝向 + voc 喊 → 替人喊话） ・ provoke 激怒；激起 （pro- 前 + voke → 喊到面前来挑事） ・ evoke 唤起，引起 （e- 出 + voke → 把记忆喊出来） ・ voice 声音；嗓音 （vox 的变体，直接进入英语）
本义「喊」 → vocal 嗓子的、vocabulary 词汇 ｜ 「替人喊话」 → advocate 提倡者 ｜ 「喊出来」 → evoke 唤起 ｜ 「叫到面前来」 → provoke 激起/挑衅
口语/生活用：The loud music provoked complaints from the neighbors. 那震天响的音乐惹来了邻居们的投诉。
6graph = write, draw（写，画）【希腊】
photograph 照片；拍照 （photo 光 + graph → 用光来刻画） ・ autograph 亲笔签名 （auto 自己 + graph → 自己写） ・ paragraph 段落 （para 旁边 + graph → 段旁的刻痕标记） ・ biography 传记 （bio 生命 + graphy → 书写人生） ・ graphic 图画的；生动的 （graph + -ic → 像刻出来一样形象） ・ telegraph 电报 （tele 远 + graph → 远处传来刻写的字）
本义「刻画」 → autograph 亲笔签名、graphic 图像的 ｜ 「用光刻画」 → photograph 照片 ｜ 「写人生」 → biography 传记 ｜ 「文字的记号」 → paragraph 段落
口语/生活用：Can I get your autograph? 能给我签个名吗？
7chron = time（时间）【希腊】
chronic 慢性的；长期的 （chron 时间 + -ic → 拖很久的） ・ chronological 按时间顺序的 （chronology 编年 + -al） ・ synchronize 使同步 （syn- 一起 + chron → 时间调到一起） ・ chronicle 编年史 （chron 时间 + -icle → 按时记下的史） ・ anachronism 时代错误 （ana- 回 + chron + -ism → 放错时间的东西） ・ chronometer 精密计时器 （chrono 时间 + meter 测量 → 量时间的仪器）
本义「时间」 → chronic 慢性的、chronological 按时间顺序的 ｜ 「把时间对起来」 → synchronize 使同步 ｜ 「量时间的工具」 → chronometer 精密计时器 ｜ 「把时间记下来」 → chronicle 编年史
口语/生活用：The historical photos are arranged in chronological order. 这些历史照片是按时间顺序排列的。
8pre- = before（在前，预先）【拉丁】
prepare 准备 （pre- 先 + pare 弄好 → 提前弄好） ・ predict 预测 （pre- 先 + dict 说 → 提前说出来） ・ preview 预告片；预览 （pre- 先 + view 看 → 先睹为快） ・ prefix 前缀 （pre- 前 + fix 固定 → 固定在前的部分） ・ preheat 预热 （pre- 先 + heat 加热 → 先加热） ・ preschool 学龄前（教育） （pre- 前 + school 学校 → 上学之前）
本义「前面」 → prefix 前缀、preschool 学前班 ｜ 「提前做」 → prepare 准备、preheat 预热 ｜ 「提前说」 → predict 预测 ｜ 「提前看」 → preview 预告片
口语/生活用：Make sure you preheat the oven to 200 degrees before baking. 烤东西前一定要把烤箱预热到 200 度。
9dis- = apart, not（分离，否定）【拉丁】
disagree 不同意 （dis- 否定 + agree 同意） ・ disappear 消失 （dis- 反 + appear 出现 → 出现的反面） ・ disconnect 断开连接 （dis- 分开 + connect 连接） ・ discount 打折；折扣 （dis- 减去 + count 数 → 从价格里扣掉） ・ discover 发现 （dis- 去掉 + cover 遮盖 → 掀开盖子看到） ・ dislike 不喜欢 （dis- 否定 + like 喜欢）
本义「分开」 → disconnect 断开、discount 打折 ｜ 「取反」 → disappear 消失、dislike 不喜欢 ｜ 「去掉遮盖」 → discover 发现
口语/生活用：I really dislike waking up early on weekends. 我真的很讨厌周末早起。
10-ly = …的 / …地（形容词·副词后缀）【古英语】
friendly 友好的 （friend 朋友 + -ly 像…样 → 像朋友的） ・ quickly 快速地 （quick 快 + -ly → 副词化） ・ daily 每日的；每天 （day 日 + -ly → 一天天的） ・ lovely 可爱的；美好的 （love 爱 + -ly → 让人爱的） ・ lonely 孤独的 （lone 独自 + -ly → 独自一人的） ・ monthly 每月（的） （month 月 + -ly → 一月一次）
līc「身体」 → 古英语 -lic「像…样子的」 → 形容词后缀 friendly 友好的 ｜ 再由形容词加 -ly → 副词后缀 quickly 快速地、daily 每天地
口语/生活用：She spoke so quickly that I couldn't follow. 她说得太快，我跟不上。
