词根词缀每日积累 · Day 4

2026 年 8 月 7 日 ｜ 词根 7 个 · 词缀 3 个 ｜ 附词源与演化
1ven / vent = come（来）【拉丁】
💡 记法：event 事件就是"发生(来了)的事"；adventure 冒险 = 将来未知的事。 词源：拉丁语 venire「来、到达」；源自印欧语 *gwa-「来、去」（英语 come 同源）。 演化：本义「来」 → event 发生的事=事件、avenue 通向的地方=大街 ｜ 「一起来」 → convention 大会 ｜ 「先到一步」 → prevent 阻止 ｜ 「找到(脑子里来的)」 → invent 发明
  • event 事件；活动 （e- 出 + vent → 冒出来的事）
  • prevent 阻止；预防 （pre- 先 + vent → 先到挡住）
  • invent 发明 （in- 里 + vent → 从脑子里"来"出来）
  • convention 大会；惯例 （con- 一起 + vent → 聚到一起）
  • adventure 冒险 （ad- 朝 + vent → 朝着要来的事去）
  • avenue 大街；大道 （通向某处的路）
口语/生活用：What time does the event start tonight? 今晚的活动几点开始？
2fer = carry, bring（携带，带来）【拉丁】
💡 记法：transfer 转车 = 从一处"带"到另一处，fer 就是"搬"。 词源：拉丁语 ferre「携带、带来、承受」；源自印欧语 *bher-「携带」（英语 bear 同源，birth 出生也来自"被带来"）。 演化：本义「带」 → transfer 转移、offer 呈上 ｜ 「带到前面」 → prefer 更喜欢 ｜ 「带到一起商量」 → confer 商议 ｜ 「带(回)来参照」 → refer 参考 ｜ 「在下面承受」 → suffer 受苦
  • transfer 转移；换乘 （trans- 跨越 + fer → 带过去）
  • prefer 更喜欢 （pre- 前 + fer → 把某个放到前面）
  • offer 提供；提议 （of- 向前 + fer → 呈上）
  • refer 参考；提及 （re- 回 + fer → 带回来对照）
  • suffer 遭受；受苦 （suf- 在下 + fer → 在下面承担）
  • conference 会议 （con- 一起 + fer → 把想法带到一起）
口语/生活用：Can you help me transfer the photos to my new phone? 你能帮我把照片转到新手机吗？
3ceed / cess = go（走）【拉丁】
💡 记法：succeed 成功 = 紧跟在后"往前走"；exceed 超过 = 走出去超出。 词源：拉丁语 cedere「走、前进、退让」，过去分词 cessus；源自印欧语 *ked-「走」。 演化：本义「走」 → proceed 继续前进、process 过程 ｜ 「跟上去走」 → succeed 成功 ｜ 「走出去」 → exceed 超过 ｜ 「往回走」 → recede 后退 ｜ 「走过去」 → access 进入
  • proceed 继续进行 （pro- 向前 + ceed → 往前走）
  • process 过程；流程 （一直往前走的步骤）
  • succeed 成功 （suc- 跟随 + ceed → 跟着走到底）
  • exceed 超过 （ex- 出 + ceed → 走出界限）
  • access 进入；使用权 （ac- 向 + cess → 走过去）
  • successful 成功的 （succeed 的形容词）
口语/生活用：Please proceed to the boarding gate. 请前往登机口。（机场广播超常见）
4pend / pens = hang; weigh（悬挂；称量）【拉丁】
💡 记法：depend 依赖 = "挂"在别人身上；expensive 贵 = "称"出来的重量重。 词源：拉丁语 pendere「悬挂；称量」——同一词根两个相关义：东西挂着必然下垂、用秤"挂"起来称重；过去分词 pensus。 演化：「悬挂」义 → depend 挂在上面=依赖、suspend 悬挂/暂停、pendulum 钟摆 ｜ 「称量」义 → expense 花费、spend 花钱（把钱"称"出去）
  • depend 依赖；取决于 （de- 向下 + pend → 挂在下面）
  • suspend 暂停；悬挂 （sus- 在下 + pend → 挂起来→悬着）
  • independent 独立的 （in- 不 + depend 依赖 + -ent）
  • expensive 昂贵的 （ex- 出 + pens → 称出去的钱多）
  • spend 花费 （把钱称出去）
  • pendulum 钟摆 （挂着摆动的装置）
口语/生活用：The meeting is suspended until further notice. 会议暂停，另行通知。
5jur / jus = law, right（法律，权利）【拉丁】
💡 记法：just 公正 = 符合"法"；injure 伤害 = 侵犯"权利"。 词源：拉丁语 jus（属格 juris）「法律、权利」，派生动词 jurare「发誓」；与英语 justice、judge 同源。 演化：本义「法/权利」 → justice 正义、just 公正的 ｜ 「无权利」 → injure 伤害 ｜ 「说法之人」 → judge 法官 ｜ 「宣布法」 → jury 陪审团、jurisdiction 司法权 ｜ 「证明合法」 → justify 证明正当
  • justice 正义；司法 （jus 法 + -ice 名词）
  • judge 法官；评判 （jus + dicere 说 → 说法之人，d 脱落）
  • jury 陪审团 （jurare 发誓 → 宣誓的人）
  • injure 伤害 （in- 不 + jur → 不尊重权利）
  • justify 证明…正当 （just 公正 + -ify 使）
  • jurisdiction 司法权；管辖权 （juris 法 + diction 说 → 说了算的范围）
口语/生活用：The jury took three days to reach a verdict. 陪审团花了三天作出裁决。
6path = feel, suffer（感受，承受）【希腊】
💡 记法：patient 病人 = "承受病痛的人"；sympathy 同情 = 一起"感受"。 词源：希腊语 pathos「受苦、感受、情感」；源自印欧语 *kwent(h)-「受苦」。 演化：本义「感受」 → sympathy 一起感受=同情、empathy 共情 ｜ 「无感受」 → apathy 冷漠 ｜ 「承受病痛的人」 → patient 病人/耐心的 ｜ 「惹人怜」 → pathetic 可怜的
  • sympathy 同情 （sym- 一起 + path → 感同身受）
  • empathy 共情 （em- 在内 + path → 设身处地体会）
  • apathy 冷漠；无动于衷 （a- 无 + path → 没有感受）
  • patient 病人；有耐心的 （承受苦痛的人→能忍受的）
  • patience 耐心 （能承受等待）
  • pathetic 可怜的；可悲的 （让人心里难受的）
口语/生活用：I have a lot of sympathy for people who work two jobs. 我非常同情做两份工作的人。
7therm = heat（热）【希腊】
💡 记法：保温瓶 thermos 就是"热"瓶；thermometer 温度计 = 测"热"的仪器。 词源：希腊语 thermē「热」、thermos「热的」；印欧语词根 *ghwer-「热、暖」（英语 warm 同源）。 演化：本义「热」 → thermal 热的、thermometer 温度计 ｜ 「控温装置」 → thermostat 恒温器 ｜ 「热+电」 → geothermal 地热 ｜ 「低于正常体温」 → hypothermia 失温
  • thermal 热的；保暖的 （therm + -al 形容词）
  • thermometer 温度计 （thermo 热 + meter 测量 → 测温度）
  • thermostat 恒温器 （thermo + stat 固定 → 固定温度）
  • geothermal 地热的 （geo 地 + thermal 热的）
  • thermos 保温瓶 （希腊语"热的"，品牌名通用化）
  • hypothermia 体温过低 （hypo- 低于 + therm → 失温）
口语/生活用：The water temperature feels perfect for swimming. 水温正适合游泳。
8-ment = 名词后缀（…的行为 / 结果 / 状态）【拉丁】
💡 记法：动词 + -ment = 名词：develop→development，agree→agreement，非常能产。 词源：拉丁语名词后缀 -mentum，经古法语 -ment 进入英语；加在动词后表行为、结果、工具或状态。 演化：拉丁语 -mentum（表"行为的手段/结果"）→ 法语 -ment → 英语大量沿用，现代英语也可直接给英语本族动词加：enjoy→enjoyment、settle→settlement
  • development 发展；开发 （develop 发展 + -ment）
  • agreement 协议；同意 （agree 同意 + -ment）
  • environment 环境 （environ 环绕 + -ment）
  • payment 付款；报酬 （pay 支付 + -ment）
  • statement 陈述；声明 （state 陈述 + -ment）
  • apartment 公寓 （意大利语 apartamento，房间分开的住所）
口语/生活用：We signed the agreement yesterday. 我们昨天签了协议。
9-ness = 名词后缀（…的状态 / 性质）【古英语】
💡 记法：形容词 + -ness = 名词：happy→happiness，kind→kindness。英语最本士的后缀之一。 词源：古英语 -nes(s)，源自日耳曼语 *-inassus-；与德语 -nis、荷兰语 -nis 同源，是英语土生土长的名词后缀。 演化：古英语时期就把形容词变成"状态名词"：beorhtnes 光亮（今 brightness）→ 现代几乎能给任何形容词加：darkness、weakness、carelessness
  • happiness 幸福 （happy 幸福 + -ness，y→i）
  • kindness 善良；好意 （kind 善良 + -ness）
  • darkness 黑暗 （dark 黑暗 + -ness）
  • weakness 弱点；虚弱 （weak 弱 + -ness）
  • business 商业；生意 （busy 忙碌 → 忙的事）
  • awareness 意识；觉察 （aware 察觉 + -ness）
口语/生活用：I appreciate your kindness. 我很感激你的好意。
10inter- = between（在…之间）【拉丁】
💡 记法：internet 互联网 = 各国网络"之间"相连；interview 面试 = 互相"看"。 词源：拉丁语 inter「在…之间、在…之中」；源自印欧语 *en-tero-（比较级，= 在里面的），与 in、enter 同源。 演化：本义「之间」 → international 国际的、internet 互联网 ｜ 「从中间切断」 → interrupt 打断 ｜ 「互相看」 → interview 面试 ｜ 「掺进中间」 → interfere 干涉 ｜ 「互相作用」 → interact 互动
  • international 国际的 （inter- 之间 + nation 国家 + -al）
  • internet 互联网 （inter- 之间 + net 网络 → 网络相连）
  • interrupt 打断 （inter- 中间 + rupt 断 → 从中断开）
  • interview 面试；访谈 （inter- 互相 + view 看 → 互相对看）
  • interfere 干涉；妨碍 （inter- + fere 打 → 打进中间）
  • interact 互动 （inter- 互相 + act 行动）
口语/生活用：Sorry to interrupt you for a second. 抱歉打断你一下。
