词根词缀每日积累 · Day 6

2026 年 8 月 10 日 ｜ 词根 7 个 · 词缀 3 个 ｜ 附词源与演化

词根（7 个）

1man / manu = hand 手
💡 记法：man=手，manager「经理」就是"一手操持大局的人" 词源：拉丁语 manus「手」，源自印欧语 *man-「手」 演化：手 → 用手操作 → 掌握/管理 → 说明书、手稿
  • manual 手册、手工的 （manu + -al，用手做的→说明书）
  • manage 管理、经营 （man + -age，用手操控一切）
  • manuscript 手稿 （manu + script=写，用手写的稿子）
  • manipulate 操纵 （man + -ipulate，用手摆布→暗中操控）
  • manufacture 制造 （manu + fact=做，用手做→工厂生产）
  • maneuver 机动、巧妙操作 （man + -euver，用手把持→操控）
口语/生活用：Can you help me with this manual? I can't figure out how to assemble the bookshelf. 你能帮我看看这本说明书吗？我不知道怎么组装这个书架。
2mov / mot / mob = move 移动
💡 记法：mov=move，车子是移动的，所以叫 mobile（手机） 词源：拉丁语 movere「移动」，完成分词 motus；另 mobilis「可移动的」，源自印欧语 *mew-「推、移动」 演化：移动 → 情感被"触动"(emotion) ｜ 机械动力(motor) → 可随身移动的(mobile)
  • move 移动 （经法语 mover 进入英语）
  • motion 运动、动作 （mot + -ion）
  • motor 马达、发动机 （mot + -or 者，驱动者）
  • mobile 可移动的、手机 （mob + -ile 能…的，手机=随身物）
  • emotion 情绪 （e- 出 + mot + -ion，"内心情感向外涌动"）
  • motivate 激励 （motiv + -ate，给人"推力"）
🧩 变体家族 mov- move, remove, movable（动词类）
mot- motion, motor, emotion, remote（名词/抽象）
mob- mobile, automobile, mobilize（"能动"性质）
口语/生活用：I need to get moving — my train leaves in an hour. 我得出发了，火车一小时后开。
3curr / curs = run 跑、流
💡 记法：currency「货币」= 每天都在"流动"的东西 词源：拉丁语 currere「跑」，完成分词 cursus，源自印欧语 *kers-「跑」 演化：跑 → 水/电流"流动"(current) ｜ 钱币"流通"(currency) → 跑过的路程=课程(course)
  • current 当前的、水流 （curr + -ent，正"跑"着的→现时的）
  • occur 发生 （oc- 朝 + curr，"迎面向你跑来"→碰到/发生）
  • currency 货币 （curr + -ency，在市面上流通的东西）
  • course 课程、路线 （cours + -e，要"跑过"的一段路程）
  • cursor 光标 （curs + -or，屏幕上"跑来跑去"的小箭头）
  • excursion 远足 （ex- 出 + curs + -ion，"跑出去"玩）
🧩 变体家族 curr- current, occur, recur（进行时词干）
curs- cursor, cursory, excursion（完成分词词干）
cour- course, courier, discourse（经法语演变）
口语/生活用：It's currently raining, so I'll take an umbrella. 现在正在下雨，我带上把伞。
4clud / clus / clos = close 关闭
💡 记法：include=关"在门里"（包含），exclude=关"在门外"（排除） 词源：拉丁语 claudere「关闭」，完成分词 clausus，源自印欧语 *klau-「钩子、插销」 演化：关门 → 关在里面=包含(include) ｜ 关在外面=排除(exclude) → 话题"盖棺定论"=conclude
  • include 包含 （in- 内 + clud，关进来）
  • exclude 排除 （ex- 外 + clud，关在外面）
  • conclude 得出结论 （con- 完全 + clud，讨论彻底关闭→下结论）
  • closet 壁橱 （clos + -et 小，关起来的小空间）
  • disclose 透露 （dis- 反 + clos，"把关着的盖子揭开"）
  • exclusive 独家的 （exclus + -ive，把别人关在门外的）
🧩 变体家族 clud- include, exclude, conclude（动词原形词干）
clus- conclusion, inclusive, exclusive（分词词干）
clos- close, closet, disclose（经法语演变）
口语/生活用：The store closes at nine, so we'd better hurry. 商店九点关门，我们得快点。
5bene / bon = good 好
💡 记法：bonus「奖金」= 老板额外给的"好东西"；好人卡就是 bon 卡 词源：拉丁语 bonus「好的」(形容词)、bene「好地」(副词)，源自印欧语 *deu-「表现好、施恩」 演化：好 → 好的结果=利益(benefit) → 心肠好=仁慈(benevolent) → 额外的好东西=奖金(bonus)
  • benefit 好处、受益 （bene + fit=做，"做出来的好事"）
  • bonus 奖金 （bon + -us，额外的好东西）
  • benevolent 仁慈的 （bene + vol=愿，"愿人好的"）
  • benign 良性的 （bene + gn=出生，"生来就好的"）
  • bonanza 繁荣、富矿 （bon + -anza，西班牙语"顺风顺水"）
  • boon 恩惠、福利 （bon 的古英语变体，"天赐的好事"）
口语/生活用：A regular morning run has so many benefits. 规律晨跑有说不完的好处。
6frag / fract = break 打碎
💡 记法：fracture「骨折」= 骨头"打碎"了；fraction「分数」= 把整体"掰开"的一块 词源：拉丁语 frangere「打碎」，完成分词 fractus，源自印欧语 *bhreg-「打碎」 演化：打碎 → 碎片(fragment) → 易碎的(fragile) ｜ 掰开的一块 → 数学分数(fraction)
  • fragment 碎片 （frag + -ment，碎下来的东西）
  • fragile 易碎的 （frag + -ile 易…的）
  • fracture 骨折、断裂 （fract + -ure）
  • fraction 分数、一小部分 （fract + -ion，被掰开的一块）
  • infraction 违规 （in- 使 + fract，"打破"规定）
  • refract 折射 （re- 反 + fract，光线被打"碎"反弹）
🧩 变体家族 frag- fragment, fragile（现在时词干）
fract- fracture, fraction, infraction, refract（分词词干）
⚠️ 注意 fragrant「芬芳的」来自另一个词根 fragrare「散发香味」，与"打碎"无关
口语/生活用：Be careful with that glass — it's really fragile. 小心那个玻璃杯——它特别容易碎。
7nov = new 新
💡 记法：novel「小说」= 当年"新奇"的体裁；renovate「翻新」= 让它重新变新 词源：拉丁语 novus「新的」，源自印欧语 *newo-「新」；与英语 new、希腊语 neos（neo-）同源 演化：新 → 新作品(novel) ｜ 新的人(novice) → 使变新(renovate) → 从新处下手=创新(innovate)
  • novel 小说、新奇的 （nov + -el，古时"新体裁"→小说）
  • novice 新手 （nov + -ice，"新来的"）
  • innovate 创新 （in- 使 + nov + -ate，引入新的）
  • renovate 翻新 （re- 再 + nov + -ate，让旧的重新变新）
  • novelty 新奇、小玩意 （nov + -el + -ty，新东西）
  • nova 新星 （nov + -a，天文学上突然"变亮的新星"）
🧬 同源对照 novus（拉丁）→ novel / renovate ｜ new（英语，日耳曼系） ｜ neos（希腊）→ neon「霓虹」、neoclassical
口语/生活用：She renovated the whole apartment — it looks brand new now. 她把整套公寓翻新了，现在看起来焕然一新。

词缀（3 个）

8-ive = 有…性质的、倾向于…的（形容词后缀）
💡 记法：act「行动」+ -ive = active「爱行动的、积极的」 词源：拉丁语后缀 -ivus，经法语 -if / -ive 进入英语 演化：拉丁 -ivus → 法语 -if/-ive → 英语 -ive，构成"有…能力的、倾向于…的"形容词
  • active 积极的、活跃的 （act + -ive，爱行动的）
  • creative 有创造力的 （create + -ive）
  • impressive 令人印象深刻的 （impress + -ive，能压进心里的）
  • explosive 爆炸的 （explode 变 e→sive）
  • decisive 果断的 （decide 变 de→cisive，能一锤定音的）
  • productive 高效的 （product + -ive，能不断产出的）
💡 深度辨析：四大形容词后缀 -ive 强调"倾向于做、有能力做"：active, creative, decisive
-ous 强调"充满、具…性质"：dangerous, famous, nervous
-al 中性"与…有关"：natural, personal, cultural
-ic 偏学术、体系化"…的"：economic, historic, academic
例：act → active（主动的，爱行动）；而 economy → economic（经济学的）
口语/生活用：She's very creative — she can turn almost anything into art. 她特别有创造力——几乎什么都能做成艺术。
9trans- = across / beyond 横过、超越
💡 记法：trans = "从这边运到那边"，transport 就是"搬运过境" 词源：拉丁语 trans「横过、到…另一边」，源自印欧语 *terh₂-「穿过」 演化：横穿 → 空间转移(transfer) ｜ 转变(transform) ｜ 超越常规(transcend)
  • transport 运输 （trans + port=搬运，搬过境）
  • transfer 转移、转账 （trans + fer=携带）
  • transform 转变 （trans + form=形态，变到另一种形态）
  • translate 翻译 （trans + late=携带，"把意思带过去"）
  • transparent 透明的 （trans + parent=显现，能看穿对面）
  • transit 过境 （trans + -it=走）
💡 深度辨析：trans- 三大义项 1. 横穿/跨越：transport, transfer, transit, transcontinental
2. 转变/改变：transform, translate, transplant「移植」
3. 超越/超常规：transcend「超越」, transhuman, transgender
trans- 都带"从一边到另一边"的移动感，与单纯表"穿过"的 per-（through）不同：trans- 强调到达另一端，per- 强调整个过程。
口语/生活用：I need to transfer some money to my savings account. 我得转点钱到我的储蓄账户里。
10ex- / e- = out of 向外、出于
💡 记法：exit「出口」= "走出去"的地方；ex-wife「前妻」= "已经出去"的婚姻 词源：拉丁语 ex「向外、出于」，源自印欧语 *eǵh₁s「出去」；在辅音前常弱化为 e- 演化：向外 → 空间出去(exit) ｜ 前任(ex-president) ｜ 语气加强(耗尽 exhaust)
  • exit 出口 （ex + -it=走）
  • export 出口（商品） （ex + port=运，运出去）
  • expand 扩张 （ex + pand=展开，向外展开）
  • exclude 排除 （ex + clud=关闭，关在门外）
  • expect 期待 （ex + spect=看，"向外看"→期盼）
  • explain 解释 （ex + plain=平坦，"摊开说明白"）
💡 深度辨析：ex- 三大义项 + 与 out- 对比 1. 向外/出来：exit, export, extract, expand
2. 前任/过去的：ex-president, ex-wife, ex-boyfriend
3. 彻底/完全（加强语气）：exhaust「耗尽」, exclaim「呼喊」, explode「爆炸」
辨析 ex- vs out-：ex- 拉丁来源、偏书面正式（export, extract）；out- 日耳曼来源、口语常用（outlet, outside）。意思相近，语域不同。
口语/生活用：Can you explain this rule one more time? I still don't get it. 你能再解释一遍这条规则吗？我还是没懂。
