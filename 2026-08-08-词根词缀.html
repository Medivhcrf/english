词根

1cap / capt / cept / ceive = take, seize（拿、抓、获取）
💡 记法：ceive 就是"拿"——re- 回 + ceive = 拿回来 = receive 收到；ac- 去 + cept = 去拿 = accept 接受 词源：拉丁语 capere「拿、抓、获取」，过去分词 captus；现在时词干变体 cip-（如 incipient）；源自原始印欧语 *kap-「抓住」（与英语 have、heave 同源） 演化：抓住 → capture 捕获 ｜ 拿回来 → receive 收到 ｜ 拿到一起 → 脑中抓住 → concept 概念 ｜ 去拿 → 接受 → accept 接受 ｜ 拿出去 → 排除 → except 除外 ｜ 透过表面去拿 → perceive 感知
  • capture 捕获、俘获 （capt 抓 + -ure 名词 → 抓住）
  • receive 收到、接到 （re- 回 + ceive 拿 → 拿回来）
  • concept 概念、观念 （con- 一起 + cept 拿 → 拿到一起形成的东西）
  • accept 接受、同意 （ac- 去 + cept 拿 → 去拿过来）
  • except 除……之外 （ex- 出 + cept 拿 → 拿出去）
  • perceive 感知、察觉 （per- 贯穿 + ceive 拿 → 透过表面去领会）
口语/生活用：I didn't receive your message until this morning. 我今天早上才收到你的消息。
2gen / gener = birth, kind, race（出生、种类、种族）
💡 记法：gen 就是 gene（基因）的来源——基因决定你如何"出生"；generate = gen 生+erate = 产生 词源：拉丁语 genus, generis「出生、种族、种类」，动词 gignere「生育」；源自原始印欧语 *gene-「生育、产生」（同源：希腊语 genos「种族」、梵语 janati「生育」） 演化：生育 → 产生 → generate 产生 / generation 一代人 ｜ 种族 → 种类 → 普遍的 → general 一般的 ｜ 高贵出身 → 慷慨 → generous 慷慨的 ｜ 天生的 → 真正的 → genuine 真正的
  • generate 产生、生成 （gener 生 + -ate → 使产生）
  • generation 一代人、世代 （gener 生 + -ation → 生出来的一批人）
  • general 一般的、普遍的；将军 （gener 种类 + -al → 全种类的）
  • generous 慷慨的、大方的 （gener 高贵出身 + -ous → 出身高贵的做派）
  • genuine 真正的、真诚的 （gen 天生 + -u- + -ine → 天生如此的）
  • gene 基因 （gen 生 → 遗传的基本单位）
口语/生活用：My grandfather was incredibly generous — he'd give you his last dollar. 我爷爷慷慨得不得了——他会把最后一美元都给你。
3vit / viv = life, live（生命、生活、活着）
💡 记法：viv 就是"活"——survive = sur- 超过 + viv 活 + e = 活得比别人久 = 幸存；vivid = 活生生的=生动的 词源：拉丁语 vīta「生命」、vīvere「活着」；源自原始印欧语 *gʷeih₃-「活着」（同源：希腊语 bios「生命」、英语 quick 古义「活的」） 演化：活着 → vivid 生动的 ｜ 活过 → 幸存 → survive 幸存 ｜ 关乎生命的 → vital 至关重要的 ｜ 生命所需之物 → vitamin 维生素 ｜ 再次活过来 → revive 复活/复兴
  • vivid 生动的、鲜明的 （viv 活 + -id → 活生生的）
  • survive 幸存、活下来 （sur- 超过 + viv 活 + -e → 活得比别人久）
  • vital 至关重要的、生命的 （vit 生命 + -al → 关乎生命的）
  • vitamin 维生素 （vit 生命 + amine 胺 → 维持生命的胺类物质）
  • revive 复活、复兴、恢复 （re- 再次 + viv 活 + -e → 再次活过来）
  • vivacious 活泼的、快活的 （viv 活 + -acious 倾向……的 → 充满活力的）
口语/生活用：Drinking enough water is vital for staying healthy. 喝足够的水对保持健康至关重要。
4grad / gress = step, go（步、行走、级别）
💡 记法：grad 和 grade（等级）是同一个词——一步一步往上走就是升级；progress = pro- 向前 + gress 迈步 = 进步 词源：拉丁语 gradus「步、台阶、级别」、动词 gradī「迈步、行走」，过去分词 gressus；源自原始印欧语 *ghredh-「行走」 演化：步 → 等级 → grade 等级 / gradual 逐步的 ｜ 向前迈步 → progress 进步 ｜ 向对面迈步 → 攻击 → aggressive 侵略的 ｜ 向上迈步 → upgrade 升级 ｜ 迈步出去 → graduate 毕业
  • grade 等级、成绩、年级 （grad 步/级 + -e → 台阶 → 等级）
  • gradual 逐渐的、逐步的 （grad 步 + -u- + -al → 一步一步的）
  • progress 进步、进展 （pro- 向前 + gress 迈步 → 向前走）
  • aggressive 侵略的、好斗的、积极的 （ag- 向 + gress 迈步 + -ive → 向对方迈步）
  • upgrade 升级、提升 （up- 向上 + grad 步/级 + -e → 往上走一级）
  • graduate 毕业；毕业生 （grad 步 + -u- + -ate → 迈出新的一步）
口语/生活用：You're making great progress with your English — keep it up! 你英语进步很大——继续加油！
5spir = breathe（呼吸）
💡 记法：spir = 呼吸——in- 入 + spire = 吹气进去 = inspire 激励；ex- 出 + (s)pire = 呼出最后一口气 = expire 到期 词源：拉丁语 spīrāre「呼吸、吹气」；源自原始印欧语 *(s)peis-「吹气」（与古英语 fīst「屁」远亲同源，皆有"出气"之意） 演化：呼吸 → 灵魂 → spirit 精神/灵魂 ｜ 吹入气息 → 激励 → inspire 激励/启发 ｜ 呼气出去 → 终结 → expire 到期/断气 ｜ 一起呼吸 → 密谋 → conspire 共谋 ｜ 向往之气 → aspiration 志向
  • spirit 精神、灵魂、烈酒 （spir 呼吸 + -it → 呼吸=生命之气=灵魂）
  • inspire 激励、启发、赋予灵感 （in- 入 + spir 呼吸 + -e → 吹气进去）
  • expire 到期、失效、断气 （ex- 出 + (s)pir 呼吸 + -e → 呼出最后一口气）
  • respiration 呼吸（作用） （re- 反复 + spir 呼吸 + -ation → 反复呼吸）
  • conspire 密谋、共谋、串通 （con- 一起 + spir 呼吸 + -e → 同呼吸→同谋）
  • aspiration 志向、抱负、渴望 （a- 向 + spir 呼吸 + -ation → 向往的气息）
口语/生活用：That speech really inspired me to work harder on my goals. 那个演讲真的激励了我更努力去追求目标。
6ver = true（真、真实）
💡 记法：ver 就是 very（非常）的词根——very 本义是"真正地"→ 后来变成强调词；verify = ver 真+ify 使=验证 词源：拉丁语 vērus「真实的、真正的」；源自原始印欧语 *weh₁ros「真实的、值得信赖的」（同源：古英语 wǣr「信约」、德语 wahr「真的」） 演化：真实 → 验证 → verify 验证 / verdict 裁决 ｜ 真正地 → 极其 → very 非常 ｜ 真实 → 诚实 → veracity 真实性 ｜ 近似真实的 → verisimilitude 逼真
  • verify 验证、核实、确认 （ver 真 + -ify 使 → 使其为真→验证）
  • verdict 裁决、判决、定论 （ver 真 + dict 说 → 说真话→裁决）
  • very 非常、很；真正的 （ver 真 + -y → 真正地→强调词）
  • veracity 真实性、诚实 （ver 真 + -acity 性质 → 真实性质）
  • veritable 名副其实的、真正的 （ver 真 + -itable 可……的 → 可真认的）
  • verisimilitude 逼真、貌似真实 （veri 真 + simil 相似 + -itude → 与真相似）
口语/生活用：Can you verify your email address before we continue? 你能先验证一下邮箱地址我们再继续吗？
7mort = death（死亡）
💡 记法：mort = 死——mortal 终有一死的；mortgage = mort 死 + gage 抵押 → 死抵=按揭（还到死或抵押失效才结束） 词源：拉丁语 mors, mortis「死亡」；源自原始印欧语 *mer-「死亡」（同源：梵语 marati「死亡」、希腊语 brotos「凡人」、英语 murder） 演化：死亡 → mortal 终有一死的 ｜ 不死的 → immortal 不朽的 ｜ 死的抵押 → 房贷 → mortgage 按揭贷款 ｜ 使死去 → 使尴尬 → mortify 使难堪 ｜ 死后僵硬 → rigor mortis 尸僵
  • mortal 终有一死的；凡人 （mort 死 + -al → 会死的）
  • immortal 不朽的、永生的 （im- 不 + mort 死 + -al → 不死的）
  • mortgage 按揭贷款、抵押 （mort 死 + gage 抵押 → 死抵→房贷）
  • mortify 使难堪、使羞愧 （mort 死 + -ify 使 → 使人想死→难堪）
  • mortuary 太平间、殡仪馆 （mort 死 + -u- + -ary 场所 → 放死者的地方）
  • postmortem 验尸；事后分析 （post- 后 + mort 死 + -em → 死后）
口语/生活用：We finally paid off our mortgage — it feels amazing to be debt-free! 我们终于还清了房贷——无债一身轻太爽了！

词缀

8com- / con- / co- / col- / cor- = together, with（一起、共同、完全）
💡 记法：com-/con- = "一起"——com 一起+bine 二→把两个绑一起=combine 结合；co 一起+operate=合作 cooperate 词源：拉丁语前缀 cum「与、一起、共同」；在不同辅音前发生同化：com-（b/p/m 前）、con-（多数辅音前）、co-（元音/h/gn 前）、col-（l 前）、cor-（r 前） 演化：一起 → 聚集 → combine 结合 / connect 连接 ｜ 共同 → 合作 → cooperate 合作 / collaborate 协作 ｜ 彻底 → 加强 → confirm 确认 / complete 完成（完全填满）
  • combine 结合、组合 （com- 一起 + bine 二 → 把两个绑一起）
  • connect 连接、联系 （con- 一起 + nect 绑 → 绑在一起）
  • cooperate 合作、配合 （co- 一起 + oper 工作 + -ate → 一起工作）
  • collaborate 协作、合著 （col- 一起 + labor 劳动 + -ate → 共同劳动）
  • correlate 相关、关联 （cor- 互相 + relate 关联 → 互相关联）
  • companion 同伴、伙伴 （com- 一起 + pan 面包 + -ion → 一起分面包的人）
口语/生活用：Let's cooperate on this project — two heads are better than one. 咱们合作这个项目吧——三个臭皮匠顶个诸葛亮。
9-ous = full of, having the quality of（充满……的、具有……性质的）
💡 记法：-ous = "充满……的"——danger 危险 + ous = dangerous 充满危险的；fame 名声 + ous = famous 有名的 词源：拉丁语形容词后缀 -ōsus「充满……的、富有……的」，经古法语 -ous / -eus 传入英语 演化：充满……的 → dangerous 危险的 / famous 著名的 ｜ 具有……性质的 → nervous 紧张的 / curious 好奇的 ｜ 像……的 → mountainous 多山的 / courageous 勇敢的
  • dangerous 危险的 （danger 危险 + -ous → 充满危险的）
  • famous 著名的、有名的 （fam(e) 名声 + -ous → 充满名声的）
  • nervous 紧张的、神经质的 （nerv(e) 神经 + -ous → 充满神经紧张的）
  • curious 好奇的、求知欲强的 （cur(i) 关心 + -ous → 充满关切的）
  • generous 慷慨的、大方的 （gener 高贵出身 + -ous → 有高贵品质的）
  • courageous 勇敢的、有胆量的 （courage 勇气 + -ous → 充满勇气的）
口语/生活用：I'm a little nervous about tomorrow's job interview. 我对明天的求职面试有点紧张。
10-al = pertaining to, relating to（与……有关的、属于……的）
💡 记法：-al = "与……有关的"——person 人 + al = personal 个人的；nation 国家 + al = national 国家的 词源：拉丁语形容词后缀 -ālis「属于……的、与……有关的」；经古法语 -al / -el 传入英语；亦作名词后缀表示「动作、过程」 演化：属于……的 → personal 个人的 / national 国家的 ｜ 与……有关的 → natural 自然的 / cultural 文化的 ｜ 具有……特性的 → digital 数字的 / emotional 情感的
  • personal 个人的、私人的 （person 人 + -al → 属于个人的）
  • natural 自然的、天生的 （nature 自然 + -al → 自然的）
  • cultural 文化的 （culture 文化 + -al → 与文化的）
  • national 国家的、民族的 （nation 国家 + -al → 国家的）
  • digital 数字的、数码的 （digit 数字 + -al → 与数字有关的）
  • emotional 情感的、情绪化的 （emotion 情感 + -al → 与情感有关的）
口语/生活用：Please don't read my personal diary — that's private. 请不要看我的私人日记——那是隐私。
