词根词缀每日积累 · 补（8月19日）

词根（7 个）

1neg = deny 否认、否定
💡 记法：negative = 否定的（消极的）；negotiate = 反复"否定"推敲→谈判 词源：拉丁语 negare「否认」= ne（不）+ agere（做），"说不、反对" 演化：否认 → 否定的=negative ｜ 谈判=negotiate ｜ 不去理=neglect
  • negative 否定的、消极的 （neg + -ative，"说不的"）
  • negotiate 谈判 （neg + otium 空闲，"让双方都不闲着→磋商"）
  • neglect 忽视 （neg + lect 选，"不去选它、置之不理"，呼应 Day 8）
  • negligible 微不足道的 （neglect 变 + -ible，"小到可忽略"）
  • renegade 叛徒 （re- + neg + -ade，"违背誓言者"）
  • negation 否定 （neg + -ation）
口语/生活用：A negative attitude will hold you back. 消极的态度会让你裹足不前。
2numer = number 数字、数量
💡 记法：numerous = "数"不清的（众多的）；enumerate = 一一"数"出来（列举） 词源：拉丁语 numerus「数字、数量」，源自印欧语 *nem-「分配」（分配即计数） 演化：数字 → 数字的=numeral ｜ 众多的=numerous ｜ 列举=enumerate
  • number 数字 （numerus 的法语变体）
  • numeral 数字（词） （numer + -al，如 Roman numerals 罗马数字）
  • numerous 众多的 （numer + -ous，"数不过来的"）
  • enumerate 列举 （e- 出 + numer + -ate，"一一数出来"）
  • numerator （分数的）分子 （numer + -ator，"被数的那部分"）
  • innumerable 数不清的 （in- 不 + numerable）
口语/生活用：There were numerous reasons for canceling the event. 取消这次活动有众多原因。
3test = witness 见证、证明
💡 记法：testify = 出庭作"证"；contest = 双方"见证"比试（竞赛） 词源：拉丁语 testis「证人」，源自印欧语 *trei-「三」（第三方在场作证） 演化：见证 → 作证=testify ｜ 竞赛=contest ｜ 公开抗议=protest
  • testify 作证 （test + -ify，"成为证言"）
  • contest 竞赛、质疑 （con- 一起 + test，"双方见证比试"）
  • protest 抗议 （pro- 前 + test，"公开声明反对"）
  • test 测试 （"检验"——考验的场合）
  • attest 证明 （at- 朝 + test，"向…作证"）
  • testimony 证词 （test + -imony，"见证之词"）
口语/生活用：The workers protested against the pay cut. 工人们抗议减薪。
4us / uti = use 使用
💡 记法：useful = 可"用"的；abuse = "用"错（滥用） 词源：拉丁语 uti「使用」，完成分词 usus 演化：使用 → 有用=useful ｜ 效用=utility ｜ 用错=abuse
  • use 使用 （usus 变体）
  • useful 有用的 （use + -ful）
  • utility 效用、公用事业 （uti + -lity，"有用性"）
  • abuse 滥用 （ab- 偏离 + use，"用偏了"）
  • usage 用法 （us + -age，"使用的方式"）
  • utensil 器具 （uti + -ensil，"被使用的工具"）
口语/生活用：Don't abuse your power while you have it. 有权在手，别滥用。
5vad / vas = go 走
💡 记法：invade = 走"进"去（侵略）；evade = 溜"走"开（逃避） 词源：拉丁语 vadere「走、去」，完成分词 vasus，源自印欧语 *wedh-「走」 演化：走 → 走进=invade ｜ 走开=evade ｜ 走到各处=pervade
  • invade 侵略 （in- 进 + vade，"走进去强占"）
  • evade 逃避 （e- 出 + vade，"溜走躲开"）
  • pervade 弥漫 （per- 贯穿 + vade，"走到各处"）
  • invasion 入侵 （invad 变 + -sion）
  • evasive 回避的 （evad 变 + -sive）
  • wade 涉水 （同源词，"在水中走"）
🧬 同源对照 vadere（拉丁）→ invade, evade, pervade ｜ wade（英语"涉水行走"）——同为 PIE *wedh-「走」（v/w 对应）
口语/生活用：Soldiers invaded the city at dawn. 黎明时分，士兵侵入了这座城市。
6auto = self 自己（希腊）
💡 记法：automatic = "自己"会动；automobile = "自己"会走的车 词源：希腊语 autos「自己、自身」 演化：自己 → 自动=automatic ｜ 汽车=automobile ｜ 亲笔签名=autograph
  • automatic 自动的 （auto + mat 动 + -ic，"自己会动"）
  • automobile 汽车 （auto + mobil 移动，呼应 Day 6，"自己会走"）
  • autograph 亲笔签名 （auto + graph 写，"自己写的字"，呼应 Day 2）
  • autobiography 自传 （auto + bio 生命 + graphy，"自己写一生"）
  • autonomous 自主的 （auto + nomos 法则，"自己定规矩"）
  • autopilot 自动驾驶 （auto + pilot 领航）
口语/生活用：The car has an automatic transmission. 这辆车是自动挡的。
7morph = form 形状、形态（希腊）
💡 记法：metamorphosis = 形态彻底"变"化（蜕变）；amorphous = 没有"形"的 词源：希腊语 morphe「形状、形态」 演化：形状 → 变形=metamorphosis ｜ 无定形=amorphous ｜ 形态学=morphology
  • metamorphosis 蜕变 （meta 变 + morph + -osis，"形态大变"）
  • amorphous 无定形的 （a- 无 + morph + -ous，"没有固定形状"）
  • morphology 形态学 （morph + -ology 学问）
  • anthropomorphic 拟人化的 （anthrop 人 + morph，赋予人形）
  • morph （图像）渐变 （计算机术语，"从一形变到另一形"）
  • morpheme 语素 （morph + -eme，"语言的最小形态"）
口语/生活用：Caterpillars undergo metamorphosis to become butterflies. 毛毛虫经过蜕变变成蝴蝶。

词缀（3 个）

8-ette = small, female 小、女性（法语）
💡 记法：cigarette = "小"雪茄（香烟）；kitchenette = 小厨房 词源：法语 -ette，表"小"或"女性" 演化：法语 -ette → 英语 -ette，表小号 / 女性 / 仿制品
  • cigarette 香烟 （cigar 雪茄 + -ette，"小雪茄"）
  • kitchenette 小厨房 （kitchen + -ette）
  • diskette 软盘 （disk + -ette，"小磁盘"）
  • etiquette 礼仪 （étiquette，"小标签→行为规范"）
  • marionette 提线木偶 （Marion + -ette，"小玛利亚人偶"）
  • coquette 卖俏女子 （coquet 卖俏 + -ette，女性形）
口语/生活用：Our hotel room has a small kitchenette. 我们的酒店房间带一个小厨房。
9out- = beyond, outside 向外、超（古英语）
💡 记法：output = 产"出"；outstanding = "站"出人群的（杰出） 词源：古英语 ut「向外」，日耳曼来源 演化：向外 → 产出=output ｜ 出色的=outstanding ｜ 超越=outdo
  • output 产出、输出 （out- + put）
  • outline 大纲、轮廓 （out- + line，"外圈线条"）
  • outlook 前景、观点 （out- + look，"向外看的视角"）
  • outdoor 户外的 （out- + door，"门外"）
  • outstanding 杰出的 （out- + standing，"站出人群之上"）
  • outbreak 爆发 （out- + break，"冲出来"）
💡 深度辨析：out- vs ex- out-（日耳曼，"向外"）：output, outstanding
ex-（拉丁，"向外"，Day 6）：export, exit, exclude
例：outbreak（口语，爆发）vs explode（书面，爆炸）——同表"冲出"，来源语域不同
口语/生活用：She's an outstanding student who always helps others. 她是一位总是帮助他人的优秀学生。
10over- = above, excessive 在上、过度（古英语）
💡 记法：overtime = 超"过"规定时间（加班）；overdue = 超过应还日期（逾期） 词源：古英语 ofer「在上、超过」，源自印欧语 *uper「上方」；与拉丁 super、希腊 hyper 同源 演化：上/过 → 超过时间=overtime ｜ 逾期=overdue ｜ 俯瞰=overlook
  • overdue 逾期的 （over- + due，"过了该还的期限"）
  • overtime 加班 （over- + time，"超过规定工时"）
  • overlook 忽视、俯瞰 （over- + look，"从上方看→漏看"）
  • overwork 过度工作 （over- + work）
  • overwhelm 压垮 （over- + whelm 覆，"盖过头顶"）
  • overseas 海外的 （over- + seas，"跨过海洋"）
🧬 同源对照 over（英语） ｜ super（拉丁，Day 9） ｜ hyper（希腊） ｜ 三兄弟同出 PIE *uper「上方」
💡 深度辨析：over- vs super- vs hyper- over-（日耳曼，"过度"）：overwork, overtime
super-（拉丁，"超/上"，Day 9）：supermarket, supernatural
hyper-（希腊，"超"，正式）：hyperactive「过度活跃」
例：overweight（口语，超重）vs superior（书面，优越）vs hypertension（医学术语，高血压）
口语/生活用：The library books are overdue — you'll owe a fine. 图书馆的书逾期了——你要交罚款。
