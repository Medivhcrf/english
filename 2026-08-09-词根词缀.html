词根

1rupt = break（打破、断裂）
💡 记法：rupt 音近"拉破他"→ 打破；想想 erupt（e- 出 + rupt 破 = "破土而出"即喷发） 词源：拉丁语 rumpere「打破、爆裂」，过去分词 ruptus，源自原始印欧语 *reup-「抓取、折断」 演化：打破 → rupture 破裂 ｜ 破开 → 突然 → abrupt 突然的 ｜ 道德上打破 → corrupt 腐败的 ｜ 向外出 → erupt 喷发 ｜ 中间插入打破 → interrupt 打断 ｜ 打破银行 → bankrupt 破产
  • rupture 破裂、断裂 （rupt 破 + -ure 名词后缀）
  • abrupt 突然的、唐突的 （ab- 离开 + rupt 破 → 突然断开）
  • corrupt 腐败的、贪污的 （cor- 完全 + rupt 破 → 道德彻底破裂）
  • erupt 喷发、爆发 （e- 出 + rupt 破 → 破土而出）
  • interrupt 打断、中断 （inter- 在中间 + rupt 破 → 从中断开）
  • bankrupt 破产的 （bank 银行 + rupt 破 → 银行账户破裂）
口语/生活用：Sorry to interrupt, but your phone is ringing. 抱歉打断一下，你手机响了。
2ject = throw, cast（投、掷、扔）
💡 记法：ject 音近"杰克特"→ 杰克特别能扔；project 往前扔=项目（往前规划），reject 扔回去=拒绝 词源：拉丁语 jacere「投、掷、扔」，过去分词 jectus，源自原始印欧语 *ye-「投掷」 演化：扔 → inject 注射 ｜ 扔回 → reject 拒绝 ｜ 向前扔 → project 项目/投影 ｜ 扔出去 → eject 弹出 ｜ 扔到下面 → subject 主题/使服从 ｜ 扔到对面 → object 物体/反对
  • inject 注射、注入 （in- 入 + ject 扔 → 扔进去）
  • reject 拒绝、排斥 （re- 回 + ject 扔 → 扔回去）
  • project 项目；投影；投射 （pro- 向前 + ject 扔 → 向前投出）
  • eject 弹出、逐出 （e- 出 + ject 扔 → 扔出去）
  • subject 主题；臣民；使服从 （sub- 在下面 + ject 扔 → 扔到脚下）
  • object 物体；目标；反对 （ob- 对面 + ject 扔 → 扔到面前的东西）
口语/生活用：I hate it when people reject my ideas without even listening. 我讨厌别人听都不听就拒绝我的想法。
3ped / pod = foot（脚）
💡 记法：ped 和"拍地"一样——脚拍地走路；pedal 脚踏板，pedestrian 用脚走路的人=行人 词源：拉丁语 pēs, pedis「脚」；希腊语 πούς, ποδός (pous, podos)「脚」；同源原始印欧语 *ped-「脚」 演化：脚 → pedal 踏板 ｜ 用脚走路的人 → pedestrian 行人 ｜ 迈脚出去 → expedition 远征 ｜ 把脚捆住 → impede 阻碍 ｜ 放脚的地方 → podium 讲台 ｜ 百脚虫 → centipede 蜈蚣
  • pedal 踏板；踩踏板 （ped 脚 + -al → 脚踩的东西）
  • pedestrian 行人、步行者 （ped 脚 + -estrian 人 → 步行的人）
  • expedition 远征、探险 （ex- 出 + ped 脚 + -ition → 迈脚走出去）
  • impede 阻碍、妨碍 （im- 入 + ped 脚 → 把脚捆住）
  • podium 讲台、领奖台 （pod 脚 + -ium 地方 → 站脚的高台）
  • centipede 蜈蚣 （centi- 百 + pede 脚 → 百足虫）
口语/生活用：I prefer walking — way more fun to be a pedestrian than stuck in traffic. 我宁愿走路——当行人比堵在路上有趣多了。
4anim = life, spirit, mind（生命、气息、心灵）
💡 记法：anim 就是 animal（动物）的前半——有生命的东西；unanimous（un- 一 + anim 心 + -ous）→ 一条心 → 一致同意的 词源：拉丁语 anima「呼吸、生命之气、灵魂」，源自原始印欧语 *ane-「呼吸」 演化：气息 → 生命 → animal 动物 / animate 赋予生命 ｜ 气息 → 心灵 → unanimous 一致同意 / magnanimous 宽宏大量 ｜ 心灵 → 情绪 → equanimity 平静、镇定
  • animal 动物 （anim 生命 + -al → 有生命之物）
  • animate 使有生命；动画的 （anim 生命 + -ate → 赋予生命）
  • unanimous 一致同意的 （un- 一 + anim 心 + -ous → 一条心）
  • magnanimous 宽宏大量的 （magn- 大 + anim 心胸 + -ous → 大心胸）
  • equanimity 平静、镇定 （equ- 均等 + anim 心 + -ity → 心态平和）
  • inanimate 无生命的 （in- 无 + anim 生命 + -ate → 无生命的）
口语/生活用：We were unanimous — everyone wanted pizza for dinner. 我们意见一致——每个人都想吃披萨当晚餐。
5sens / sent = feel, perceive（感觉、感知）
💡 记法：sens 就是英文 sense（感觉）的词根；consent = con 一起+sent 感觉 = 同感 → 同意 词源：拉丁语 sentīre「感觉、感知、意识到」，过去分词 sēnsus，源自原始印欧语 *sent-「走、找出、感知」 演化：感知 → sense 感觉 / sensitive 敏感的 ｜ 共同感受 → consent 同意 ｜ 感受 → 情绪 → sentiment 情绪 ｜ 反向感受 → resent 怨恨 ｜ 引起轰动之感 → sensation 轰动
  • sense 感觉、意识、意义 （sens 感觉 + -e → 感觉）
  • sensitive 敏感的、体贴的 （sens 感觉 + -itive 形容词 → 容易感知的）
  • consent 同意、许可 （con- 共同 + sent 感觉 → 有同感）
  • sentiment 情绪、感情 （sent 感觉 + -i- + -ment 名词 → 感受之物）
  • resent 怨恨、愤恨 （re- 反向 + sent 感觉 → 反向的感受）
  • sensation 轰动、感觉、知觉 （sens 感觉 + -ation 名词 → 强烈的感觉）
口语/生活用：You need my consent before posting that photo online. 你把那张照片发网上之前需要征得我的同意。
6ten / tin / tain = hold, keep（拿住、保持、持有）
💡 记法：tain 音近"疼"——疼也得拿住不放；container（con- 一起 + tain 拿住 + -er）= 把所有东西拿到一起的容器 词源：拉丁语 tenēre「握住、保持、持有」，源自原始印欧语 *ten-「伸展、握住」（同源：梵语 tanoti「伸展」、希腊语 teinein「拉紧」） 演化：握住 → 包含 → contain 包含 ｜ 用手握住 → 维持 → maintain 维持 ｜ 握住不放 → 保留 → retain 保留 ｜ 从下方撑住 → sustain 支撑 / sustain 持续 ｜ 连在一起握住 → continent 大陆
  • contain 包含、容纳、克制 （con- 一起 + tain 拿住 → 装在一起）
  • maintain 维持、保养、坚持 （main- 手 + tain 拿住 → 用手握住）
  • retain 保留、保持、记住 （re- 回 + tain 拿住 → 拿住不放）
  • sustain 支撑、维持、承受 （sus- 从下 + tain 拿住 → 从下方撑住）
  • continent 大陆；节制的 （con- 一起 + tin 握住 + -ent → 连成一片的大地）
  • tenant 租户、房客 （ten 持有 + -ant 人 → 持有房屋使用权的人）
口语/生活用：I try to maintain a healthy diet, but chocolate is my weakness. 我尽量保持健康饮食，但巧克力是我的软肋。
7log / logue = word, speech, reason（话、言语、道理）
💡 记法：log 就是"逻辑 logic"的来源——讲话要有逻辑；dia- 两者 + logue = 两人说话 = 对话 dialogue 词源：希腊语 λόγος (logos)「言语、道理、叙述、比例」，源自动词 λέγειν (legein)「说、收集」，源自原始印欧语 *leg-「收集、挑选」（说话即收集词语） 演化：言语 → dialogue 对话 / monologue 独白 ｜ 道理 → 推理 → logic 逻辑 ｜ 叙述 → 列举 → catalog 目录 ｜ 辩护之言 → apology 道歉 ｜ 开场之言 → prologue 序言
  • logic 逻辑、推理 （log 道理 + -ic → 关于道理的学问）
  • dialogue 对话、对白 （dia- 两者之间 + logue 话 → 两人对话）
  • monologue 独白 （mono- 单一 + logue 话 → 一个人说话）
  • catalog 目录、一览表 （cata- 完全/向下 + log → 完整列举）
  • apology 道歉、辩护 （apo- 离开 + log 话 + -y → 为自己辩护的话）
  • prologue 序言、开场白 （pro- 前 + logue 话 → 前面的话）
口语/生活用：We need to have a serious dialogue about our future plans. 我们需要就未来的计划认真谈一谈。

词缀

8sub- = under, below（在……下面、次于）
💡 记法：sub 就是"下"——subway 地下的路=地铁，submarine 海下面的=潜水艇，subtitle 下面的文字=字幕 词源：拉丁语前缀 sub「在……之下、靠近、略微」，源自原始印欧语 *upo「下、从下面往上」（与希腊语 hypo- 同源） 演化：在下面 → subway 地铁 / submarine 潜水艇 ｜ 向下 → submerge 淹没 / subside 下沉 ｜ 低于 → 次要 → subtitle 字幕 / subordinate 下属 ｜ 接近 → 替代 → substitute 替代品
  • subway 地铁 （sub 下 + way 路 → 地下的路）
  • submarine 潜水艇 （sub 下 + marine 海的 → 海下面的）
  • submerge 淹没、浸入 （sub 下 + merge 沉入 → 沉到水下）
  • subconscious 潜意识的 （sub 下 + conscious 有意识的 → 意识之下的）
  • substitute 替代品、替补 （sub 下面 + stitute 放置 → 放在下面备用）
  • subtitle 字幕、副标题 （sub 下 + title 标题 → 下面的文字）
口语/生活用：I take the subway to work every day — way faster than driving during rush hour. 我每天坐地铁上班——高峰期比开车快多了。
9-ize / -ise = to make, to become（使……化、变成）
💡 记法：-ize = "……化"——real 真实 + ize = 使成为现实 = realize 意识到/实现；organ 组织 + ize = organize 组织起来 词源：希腊语动词后缀 -ίζειν (-izein)「使成为」，经拉丁语 -izāre 和古法语 -iser 传入英语；英式英语多用 -ise，美式多用 -ize 演化：使成为 → realize 意识到/实现 / organize 组织 ｜ 使具备某特征 → specialize 专攻 / prioritize 优先处理 ｜ 以某种方式行动 → apologize 道歉 / recognize 认出 ｜ 变成某种状态 → crystallize 结晶
  • realize 意识到、实现 （real 真实 + -ize → 使成为现实）
  • organize 组织、安排 （organ 器官/组织 + -ize → 使有条理）
  • recognize 认出、承认 （re- 再次 + cogn 知道 + -ize → 再次知道）
  • specialize 专攻、专门从事 （special 特别的 + -ize → 使专精）
  • apologize 道歉 （apo- 离开 + log 话 + -ize → 用话为自己辩护）
  • prioritize 优先处理 （prior 先前的 + -it- + -ize → 把……放前面）
口语/生活用：I didn't realize how late it was until I checked my phone. 直到看手机我才意识到已经这么晚了。
10-er / -or = one who, that which（做……的人/物）
💡 记法：-er/-or 就是"……的人/机器"——teach 教 + er = 教的人 = 老师；compute 计算 + er = 计算的机器 = 电脑 词源：拉丁语施动者后缀 -or / -ātor「做……的人」；古英语 -ere「做……的人」；两者同源原始印欧语 *-tēr「施动者后缀」 演化：人 → teacher 教师 / actor 演员 / writer 作家 ｜ 工具/机器 → computer 电脑 / mixer 搅拌机 ｜ 从事某活动者 → driver 司机 / baker 面包师 / player 玩家
  • teacher 老师 （teach 教 + -er → 教的人）
  • actor 演员 （act 表演 + -or → 表演的人）
  • driver 司机 （drive 驾驶 + -er → 开车的人）
  • computer 电脑 （compute 计算 + -er → 计算的机器）
  • baker 面包师 （bake 烘焙 + -er → 烤面包的人）
  • writer 作家 （write 写 + -er → 写作的人）
口语/生活用：My dad is a baker — he wakes up at 4 a.m. every day to make fresh bread. 我爸是面包师——他每天凌晨4点起床做新鲜面包。
