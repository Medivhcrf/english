词根词缀每日积累 · Day 7

2026 年 8 月 11 日 ｜ 词根 7 个 · 词缀 3 个 ｜ 附词源与演化

词根（7 个）

1sta / stat / stit = stand 站、立
💡 记法：state「状态」= 你"站"在那里的样子；station 车站 = 站着等车的地方 词源：拉丁语 stare「站立」，完成分词 status；另有使役动词 sistere「使站立」，源自印欧语 *steh₂-「站、立」 演化：站立 → 站着的形态=状态(state) ｜ 站得住=稳定(stable) ｜ 站在身边=帮助(assist) ｜ 一直站着=坚持(persist)
  • state 状态；国家 （stat + -e，站立的形态；"立国"）
  • station 车站 （stat + -ion，站着等候的地点）
  • stable 稳定的 （sta + -able，站得住的）
  • constant 恒定的 （con- 完全 + st + -ant，一直站着的）
  • establish 建立 （e- 出 + st + -abl + -ish，使"立"起来）
  • persist 坚持 （per- 贯穿 + sist，一直站着不退缩）
🧩 变体家族 sta- state, stable, station, establish
stat- status, statute, statue
stit- constitute「构成」, institution「制度」, substitute「替代」
sist- assist「帮助」, resist「抵抗」, persist「坚持」, consist「组成」
口语/生活用：The bus station is a five-minute walk from here. 公交站离这里步行五分钟。
2val / vail = strong, worth 强壮、价值
💡 记法：valid「有效」= 站得住脚的；value「价值」= 值得 词源：拉丁语 valere「强壮、有价值」，源自印欧语 *wal-「强壮」 演化：强壮/有价值 → 价值(value) ｜ 站得住=有效(valid) ｜ 更强=占上风(prevail)
  • value 价值 （val + -ue）
  • valid 有效的、站得住脚的 （val + -id）
  • available 可获得的 （a- 到 + vail + -able，"够得着、用得上"）
  • prevail 盛行、占上风 （pre- 前 + vail，"更强大而胜出"）
  • evaluate 评估 （e- 出 + val + -uate，估出价值）
  • equivalent 等价的 （equi 等 + val + -ent）
🧩 变体家族 val- value, valid, evaluate, equivalent, valuable
vail- available, prevail（经法语演变）
口语/生活用：The coupon is still valid until the end of this month. 这张优惠券到这个月底仍然有效。
3sequ / secut / suit = follow 跟随
💡 记法：second「第二」= 跟在第一"后面"的；consequence「后果」= "跟"着发生的事 词源：拉丁语 sequi「跟随」，完成分词 secutus，源自印欧语 *sekʷ-「跟随」 演化：跟随 → 一个接一个=顺序(sequence) ｜ 跟着来=后果(consequence) ｜ 跟着追=pursue/suit
  • sequence 顺序、序列 （sequ + -ence，一个跟一个）
  • consequence 后果 （con- 完全 + sequ + -ence，"紧跟着发生的"）
  • second 第二 （sec + -und，跟在第一后面的）
  • pursue 追求、追赶 （经法语，"在后面跟着跑"）
  • executive 行政的 （ex- 出 + secut + -ive，执行命令者）
  • suit 诉讼；一套衣服 （法语，"跟随"的变体；"成套"的衣服）
🧩 变体家族 sequ- sequence, subsequent, consequence
secut- execute, executive, consecutive「连续的」
su- pursue「追求」, suit, ensue「接着发生」
sec- second「第二」, sect「派别」
口语/生活用：What were the consequences of your decision? 你的决定带来了什么后果？
4reg / rect = rule, straight 统治、直
💡 记法：rule=统治；把"弯的拉直"就是 correct（改正），直直地引路就是 direct（直接） 词源：拉丁语 regere「统治、引导」，rectus「直的、正确的」，源自印欧语 *reg-「直、指引」 演化：统治/指引 → 规则(regular) → 拉直=纠正(correct) ｜ 直路=直接(direct)
  • regular 规律的、规则的 （reg + -ul + -ar，"按规矩来的"）
  • correct 正确的；纠正 （cor- + rect，"拉直、矫正"）
  • direct 直接的；指导 （di- 分开 + rect，"指引方向"）
  • regulate 调节、管理 （reg + -ulate）
  • region 地区 （reg + -ion，"被统治的区域"）
  • rectangle 长方形 （rect + angle 角，"直角形"）
🧩 变体家族 reg- regular, region, regulate, regime「政权」
rect- correct, direct, erect「直立」, rectangle
reign/realm 经法语变体：reign「统治」, realm「王国」
口语/生活用：You should get more regular exercise. 你应该多做规律的运动。
5press = press 压
💡 记法：press「按」→ 把话"压"出来=express（表达）；把情绪"压"下去=depress（沮丧） 词源：拉丁语 premere「压」，完成分词 pressus，源自印欧语 *per-「击打、按压」 演化：压 → 压字印刷=报刊(press) ｜ 压出来=表达(express) ｜ 压进去=留下印象(impress)
  • press 按、压；报刊 （印刷术=压字）
  • express 表达；特快的 （ex- 出 + press，"把想法压出来说出"）
  • pressure 压力 （press + -ure）
  • compress 压缩 （com- 一起 + press，压到一起）
  • depress 使沮丧 （de- 下 + press，"情绪被压下去"）
  • impress 留下印象 （im- 进 + press，"压进心里"）
口语/生活用：Don't put too much pressure on yourself. 别给自己太大压力。
6vol = will, wish 意愿
💡 记法：vol=意愿，benevolent 愿人好=仁慈，malevolent 愿人坏=恶毒（呼应 Day 6 的 bene/bon） 词源：拉丁语 velle「希望」，voluntas「意愿」，源自印欧语 *welh₁-「想要、选择」 演化：意愿 → 出于自己意愿=voluntary ｜ 自愿出力=volunteer ｜ 意志力=volition
  • voluntary 自愿的 （vol + -unt + -ary）
  • volunteer 志愿者；自愿做 （vol + -unteer）
  • volition 意志、自愿 （vol + -ition，"凭自己意愿行动"）
  • benevolent 仁慈的 （bene 好 + vol + -ent，"愿人好的"）
  • malevolent 恶意的 （male 坏 + vol + -ent，"愿人坏的"）
  • voluble 健谈的 （vol + -uble，"话不停往外涌"）
口语/生活用：She volunteered to help organize the event. 她自愿帮忙组织这次活动。
7luc / lux / lumin = light 光
💡 记法：luc=光，lucid「清晰」= 脑子里像点了一盏灯 词源：拉丁语 lux/lucis「光」、lumen「光线」，源自印欧语 *leuk-「光、明亮」；与希腊语 leukos「白色」（如 leukemia 白血病）同源 演化：光 → 有光=明亮/明白(lucid) ｜ 照亮=illuminate ｜ 光能穿透=translucent（呼应 Day 6 trans-）
  • lucid 清晰的、清醒的 （luc + -id，"像有光的"）
  • illuminate 照亮；阐明 （il- 使 + lumin + -ate）
  • luminous 发光的 （lumin + -ous）
  • translucent 半透明的 （trans- 透过 + luc + -ent，"光能穿过的"）
  • luxury 奢侈 （lux + -ury，"华丽闪光的"）
  • lucid dream 清醒梦 （lucid + dream，做梦时神志清醒）
🧩 变体家族 luc- lucid, translucent, lucifer「启明星」
lux- luxury, luxuriant
lumin- illuminate, luminous, luminous
lu- （同源）luster「光泽」
口语/生活用：The moonlight illuminated the path in front of us. 月光照亮了我们前面的小路。

词缀（3 个）

8in- / il- / im- / ir- = not / into 否定、进入
💡 记法：为什么是 impossible？因为 in- 遇 p 变 im-；遇 l 变 il-、遇 r 变 ir-，发音顺口 词源：拉丁语 in-，一个前缀两种用法：① 否定（加形容词）② 进入（加动词）；随后面首字母同化：l 前→il-、p/b/m 前→im-、r 前→ir-；经法语 en-/em- 进入英语 演化：拉丁 in-（否定义 + 进入义）→ 法语 en-/em- → 英语 in-/en-/im-
  • inactive 不活跃的 （in- 不 + active，呼应 Day 6）
  • illegal 非法的 （il- 不 + legal，l 前同化）
  • impossible 不可能的 （im- 不 + possible，p 前同化）
  • irregular 不规则的 （ir- 不 + regular，r 前同化，呼应今日 reg）
  • input 输入 （in- 进入 + put）
  • inspire 激发 （in- 进入 + spir 呼吸，"吸气鼓劲"）
💡 深度辨析：否定前缀家族总动员 in- / il- / im- / ir-（拉丁，直接否定形容词）：illegal, impossible, inactive
un-（日耳曼，日常最常用）：unhappy, unclear, unfair
dis-（拉丁，主动反向动作，呼应 Day 2）：disagree, disconnect
non-（拉丁，客观分类"非"）：nonstop, nonprofit
例：correct 正确 → incorrect（in-）／可对比 Day 2 dis-、Day 3 un- 的辨析思路
口语/生活用：It's impossible to finish all this work in one day. 一天之内完成所有这些工作是不可能的。
9-ship = state, quality 状态、身份
💡 记法：ship 不是"船"！friend + ship = "做朋友"这种状态 → 友谊 词源：古英语 -scipe「状态、条件、关系」，与 shape「形状、形成」同源（"形成的状态"） 演化：古英语 -scipe → 现代英语 -ship，表示身份、关系、技能状态
  • friendship 友谊 （friend + -ship，做朋友的状态）
  • leadership 领导力 （leader + -ship）
  • citizenship 公民身份 （citizen + -ship）
  • membership 会员资格 （member + -ship）
  • scholarship 奖学金；学问 （scholar + -ship，"学者身份"→奖学金）
  • ownership 所有权 （owner + -ship）
口语/生活用：She earned a scholarship to study abroad. 她获得了出国留学的奖学金。
10-age = act, process, collective 行为、过程、集合
💡 记法：postage「邮资」= 寄信"这个行为"要付的钱；luggage「行李」= "一包包"的东西 词源：法语 -age，源自拉丁语后缀 -aticum，表示行为、状态、集合或费用 演化：拉丁 -aticum → 法语 -age → 英语 -age，含义扩展为行为/过程/集合/费用
  • usage 用法 （use + -age，使用的行为）
  • storage 储存 （store + -age）
  • marriage 婚姻 （marry + -age，"结婚"的状态）
  • package 包裹 （pack + -age，一包一包的集合）
  • percentage 百分比 （percent + -age）
  • luggage 行李 （lug + -age，拎的一堆东西）
💡 深度辨析：-age 的四种义项 1. 行为/过程：usage, storage, marriage
2. 集合/总量：package, luggage, percentage
3. 费用：postage「邮资」, damage「赔偿金」
4. 状态/关系：marriage, bondage「束缚」
口语/生活用：The package arrived two days early. 包裹提前两天到了。
