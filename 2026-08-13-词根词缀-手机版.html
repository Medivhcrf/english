词根（7 个）

1ag / act = do, drive 做、驱动
💡 记法：act = "做"；agent = 替别人"做事"的人（代理人） 词源：拉丁语 agere「做、推动」，完成分词 actus，源自印欧语 *h₂eǵ-「驱使、做」 演化：做/驱动 → 动作(act) ｜ 推动者=agent ｜ 反着"做"=react ｜ 再"做"一遍=re-enact
  • act 行动、表演 （agere 的名词，"去做"）
  • action 行动 （act + -ion）
  • active 活跃的 （act + -ive，爱行动的，呼应 Day 6）
  • agent 代理人、中介 （ag + -ent，"替人做事者"）
  • react 反应 （re- 回 + act，"对刺激做回去"）
  • exact 精确的 （ex- 出 + act，"做出来一丝不差"）
🧩 变体家族 ag- agent, agency, agenda「待办议程（要去做的事）」
act- act, action, active, react, exact, transaction「交易」
口语/生活用：Actions speak louder than words. 行动胜于言辞。
2cid / cis = cut, kill 切、杀
💡 记法：decide = 一刀"切"断犹豫（决定）；scissors = 用来"切"的剪刀 词源：拉丁语 caedere「切割、杀死」，完成分词 caesus，源自印欧语 *ka-「切」 演化：切割 → 一刀两断=decide ｜ 切掉多余=concise（简洁） ｜ 自"杀"=suicide
  • decide 决定 （de- 完全 + cid，"一刀切下定论"）
  • decisive 果断的 （decide 变 de + cisive，能当机立断的）
  • concise 简洁的 （con- 加强 + cis，"切掉废话"）
  • suicide 自杀 （sui 自己 + cide，"杀自己"）
  • precise 精确的 （pre- 前 + cis，"预先切准"）
  • scissors 剪刀 （源自 caedere 的派生，"切割工具"）
🧩 变体家族 cid- decide, suicide, pesticide「杀虫剂」
cis- decisive, concise, precise, incision「切口」
cide- homicide「杀人」, insecticide「杀虫剂」
口语/生活用：I can't decide between the two — they're both great. 这两个我选不出来——都很好。
3corp / corpor = body 身体
💡 记法：corps = 一"具"躯体→军团；corporate = 公司这个"整体" 词源：拉丁语 corpus「身体、实体」，源自印欧语 *kr̥p-「身体」 演化：身体 → 尸体(corpse) ｜ 结为"一体"=incorporate ｜ 公司的整体=corporate
  • corpse 尸体 （corp + -se，无生命之躯）
  • corporate 公司的、法人的 （corpor + -ate，"结成一体的"）
  • corporation 公司 （corpor + -ation，"法人实体"）
  • incorporate 合并、包含 （in- 入 + corpor + -ate，"纳入一体"）
  • corps 军团、团体 （法语，"一整体人马"，s 不发音）
  • physical 身体的 （源自希腊语同源词，physical exercise 锻炼身体）
🧬 同源对照 corpus（拉丁）→ corporate, corpse ｜ soma（希腊）→ somatic「身体的」, chromosome「染色体」——两个"身体"是不同词根，各走一路
口语/生活用：I work for a large corporation with offices in fifty countries. 我在一家在五十个国家设有办事处的大型公司工作。
4trib = give, pay 给予、分配
💡 记法：tribute = 献给国家的供奉；contribute = 一起"给"（贡献） 词源：拉丁语 tribuere「分配、给予」，源自 tribus「部落」（按部落分配） 演化：分配/给予 → 上缴的贡物=tribute ｜ 一起贡献=contribute ｜ 分发给众人=distribute
  • tribute 致敬、贡品 （trib + -ute，"献出之物"）
  • contribute 贡献、捐助 （con- 一起 + trib + -ute，"一起拿出"）
  • distribute 分发、分配 （dis- 分开 + trib + -ute，"分头给出去"）
  • attribute 归因于；属性 （at- 朝 + trib + -ute，"把功劳/性质分给…"）
  • retribution 报应、惩罚 （re- 回 + trib + -ution，"应得之偿还"）
  • tribunal 法庭 （tribun 保民官 + -al，"主持公道之处"）
口语/生活用：Everyone should contribute a little to keep the office clean. 每个人都应该为保持办公室整洁出一点力。
5terr / terra = earth, land 土地
💡 记法：terrace = 一层层"土地"砌的梯田；territory = 圈起来的"领地" 词源：拉丁语 terra「土地、大地」；注意与 terr「使害怕」（terrere）是两个不同词根，切勿混淆 演化：土地 → 圈占的土地=territory ｜ 地形=terrain ｜ 地球=terrestrial（陆地的）
  • territory 领土、领域 （terr + -itory，"圈占之地"）
  • terrain 地形 （terr + -ain，"土地的形态"）
  • terrace 露台、梯田 （terr + -ace，"泥土砌的台地"）
  • terrestrial 陆地的、地球的 （terrest + -rial，"大地的"）
  • subterranean 地下的 （sub- 下 + terr + -anean，"土地之下的"）
  • Mediterranean 地中海的 （medi 中 + terr + -anean，"大地中央的海"）
🧬 同源对照 terra（拉丁）→ territory, terrain ｜ geo（希腊）→ geography, geology——同表"大地"，拉丁/希腊各走一路
口语/生活用：Our company is expanding into new territory this year. 我们公司今年正在开拓新领域。
6son = sound 声音
💡 记法：person = per（透过）+ son（声音）→ 透过"声音"成为的人（人） 词源：拉丁语 sonus「声音」，源自印欧语 *swen-「发出声响」 演化：声音 → 声波=sonic ｜ 共同发声=consonant ｜ 回"声"=resonate
  • sonic 音速的、声波的 （son + -ic）
  • resonate 引起共鸣 （re- 回 + son + -ate，"声音回荡"）
  • consonant 辅音；一致的 （con- 一起 + son + -ant，"与元音一同发声"）
  • person 人 （per- 透过 + son，"透过声音面具的角色"→人）
  • sonata 奏鸣曲 （son + -ata，"奏响之曲"）
  • sonorous 洪亮的 （sonor + -ous，"声音洪大"）
🧩 变体家族 son- sonic, sonata, sonorous
sonan- consonant, resonance「共鸣」
soun- sound（经法语，直接借自 sonus）
口语/生活用：Her speech really resonated with the audience. 她的演讲深深引起了观众的共鸣。
7phil = love 爱（希腊）
💡 记法：philosophy = 爱（phil）智慧（soph）→ 哲学；Philadelphia = 兄弟之"爱"之城（费城） 词源：希腊语 philein「爱」，philos「亲爱的」；与英语 friend 同源（同出印欧语 *prāi-「喜欢」） 演化：爱 → 爱智慧=哲学(philosophy) ｜ 爱人类=博爱(philanthropy) ｜ 爱书人=bibliophile
  • philosophy 哲学 （phil + soph 智慧 + -y，"爱智慧"）
  • philanthropist 慈善家 （phil + anthrop 人类 + -ist，"爱人类者"）
  • bibliophile 藏书家 （biblio 书 + phil + -e，"爱书之人"）
  • Philadelphia 费城 （phil + adelph 兄弟，"兄弟之爱之城"）
  • philharmonic 爱乐的、交响乐团 （phil + harmon 和谐 + -ic，"爱和谐音乐的"）
  • -philia 对…的病态爱好 （后缀，如 necrophilia 恋尸癖）
🧬 同源对照 philein（希腊）→ philosophy, philanthropist ｜ friend（英语） ｜ frīōn（古英语"去爱"）——同出 PIE *prāi-「喜爱」
口语/生活用：My philosophy is simple: work hard, rest well. 我的人生哲学很简单：好好工作，好好休息。

词缀（3 个）

8de- = down, away, reverse 向下、离开、反转
💡 记法：decrease = 往下"降"；decode = "反"译回明文（解码） 词源：拉丁语 de「向下、离开、远离」，源自印欧语 *dō-「去、离开」 演化：向下/离开 → 下降(decrease) ｜ 离开=出发(depart) ｜ 反转=解除(decode)
  • decrease 减少 （de- 下 + creas 长，"往下长"）
  • decline 下降、婉拒 （de- 下 + clin 斜，"向下倾斜"）
  • depart 出发、离开 （de- 离 + part 分开，"分道离开"）
  • decode 解码 （de- 反 + code，"逆向破译"）
  • debug 调试 （de- 除 + bug 虫，"去除程序漏洞"）
  • deny 否认 （de- 加强 + ny 否定，"坚决说不"）
💡 深度辨析：de- vs dis- vs un- de-（向下/离开/反转）：decrease, depart, decode
dis-（主动反向/去除，Day 2）：disagree, disconnect
un-（单纯否定状态，Day 3）：unhappy, unclear
例：decode（反着解，de-）vs disagree（反着做，dis-）vs unfair（没公平，un-）——de- 强调"向下的方向"，dis- 强调"相反的动作"
口语/生活用：Sales usually decrease after the holiday season. 假期过后销售额通常会下降。
9-ance / -ence = 状态、性质（名词后缀）
💡 记法：important → importance（重要性）；patient → patience（耐心） 词源：拉丁语 -antia / -entia，经法语 -ance / -ence 进入英语，构成抽象名词 演化：拉丁 -antia/-entia → 法语 -ance/-ence → 英语，表"…的状态、性质"
  • importance 重要性 （important → import + -ance）
  • difference 差别 （differ + -ence，"不同之处"）
  • performance 表现、演出 （perform + -ance，"完成的状态"）
  • patience 耐心 （patient → pati + -ence，"忍受的状态"）
  • confidence 自信 （confide → confid + -ence，"相信自己的状态"）
  • assistance 帮助 （assist + -ance）
💡 深度辨析：名词后缀 -ance / -ence 与 -ity / -ness -ance / -ence（拉丁，多配 -ant/-ent 形容词）：importance, performance, difference
-ity（拉丁，Day 8 学过）：ability, reality
-ness（日耳曼，Day 4 学过）：happiness, kindness
规律：以 -ant/-ent 结尾的形容词，其名词通常用 -ance/-ence——记一个就能推另一个
口语/生活用：Practice makes perfect — your performance will improve. 熟能生巧——你的表现会进步的。
10syn- / sym- / syl- = together 一起（希腊）
💡 记法：synonym = 和另一个词"一起"一个意思（同义词）；system = 部件"合成"的整体 词源：希腊语 syn「一起、共同」；随后面辅音同化：m/p/b 前→sym-、l 前→syl- 演化：希腊 syn「一起」→ 一起=共同 ｜ 合成整体=system ｜ 同义=synonym
  • synonym 同义词 （syn + onym 名，"同名"）
  • system 系统 （sy + stem 立，"部件合成一体"）
  • symphony 交响乐 （sym + phon 声 + -y，"众声和鸣"）
  • sympathy 同情 （sym + path 感受，呼应 Day 4，"同感"）
  • syllable 音节 （syl + lab 取，"音素合在一起"）
  • synthetic 合成的 （syn + thet 放，"放到一起"）
💡 深度辨析：syn- vs com- syn- / sym- / syl-（希腊，"合成一体"）：symphony, system, sympathy
com- / con- / co-（拉丁，"共同"，补课已学）：combine, cooperate
例：symphony（希腊乐名）vs company（拉丁"共同伴面包的人"）——希腊词根多进科学/艺术词，拉丁词根多进日常词
口语/生活用：I have every sympathy for what you're going through. 我非常理解你正在经历的一切。
