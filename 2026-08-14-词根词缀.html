词根（7 个）

1aqua / aqu = water 水
💡 记法：aqua 饮料的名字就是"水"；aquarium 就是放水的地方 词源：拉丁语 aqua「水」，源自印欧语 *akʷā-「水」 演化：水 → 水族馆(aquarium) ｜ 导水的渠=aqueduct ｜ 水中孕育=aquatic
  • aquarium 水族馆 （aqua + -arium 场所）
  • aquatic 水生的 （aqua + -tic，"水的"）
  • aqueduct 引水渠 （aqua + duct 引导，呼应 Day 3）
  • aquifer 含水层 （aqua + fer 携带，蓄水的地层）
  • aquaculture 水产养殖 （aqua + culture 培育）
  • aquiline 鹰钩状的 （aquil 鹰 + -ine，与 aqua 无关，注意区分）
口语/生活用：I love watching the fish swim around the aquarium. 我喜欢看水族馆里的鱼游来游去。
2mar = sea 海
💡 记法：marine = 和海有关的；submarine = 潜到"海"下的船 词源：拉丁语 mare「海」，源自印欧语 *mori-「海」；与古英语 mere「湖」同源 演化：海 → 海军的(marine) ｜ 海事(martime) ｜ 海下的=submarine
  • marine 海洋的、海军的 （mar + -ine）
  • maritime 海事的、沿海的 （mar + -itime）
  • submarine 潜水艇 （sub- 下 + marine，海下的）
  • marina 游艇码头 （mar + -ina，海的角落）
  • mariner 水手 （mar + -iner）
  • marinate 腌渍 （mar + -inate，"用盐水/海水浸泡"）
🧬 同源对照 mare（拉丁）→ marine, submarine ｜ mere（英语古词"湖、池"）——同为 PIE *mori-「海、水体」（m 对应）
口语/生活用：Marine life is under threat from plastic pollution. 海洋生物正受到塑料污染的威胁。
3solv / solu / solut = loosen 解开、松开
💡 记法：solve = 把问题的结"解开"；dissolve = 糖"化开"溶进水里 词源：拉丁语 solvere「解开、松开」，完成分词 solutus，源自印欧语 *seu-「松开」 演化：解开 → 解开问题=solve ｜ 彻底松开=dissolve ｜ 完全松开=absolute（绝对的）
  • solve 解决 （solv + -e，解开问题之结）
  • solution 解决方案、溶液 （solu + -tion）
  • dissolve 溶解、解散 （dis- 分开 + solve，"散开溶化"）
  • resolve 决心、解决 （re- 再 + solve，"下定决心解开"）
  • absolute 绝对的 （ab- 完全 + solute，"完全松开、不受约束"）
  • soluble 可溶解的 （solu + -ble）
🧩 变体家族 solv- solve, dissolve, resolve, absolve「赦免」
solu- solution, soluble
solut- absolute, resolution「决议、决心」
口语/生活用：We need to solve this problem before the deadline. 我们必须在截止日期前解决这个问题。
4vac / van / void = empty 空
💡 记法：vacation = 把工作"清空"去休息的假期；vanish = 变成"空"消失 词源：拉丁语 vacuus「空的」、vacare「使空」；另有 vanus「空的、虚的」；法语变体 void「空」 演化：空 → 腾空(vacate) ｜ 空闲(vacant) ｜ 化为乌有=vanish ｜ 使无效=void
  • vacuum 真空 （vac + -uum，空的）
  • vacant 空缺的 （vac + -ant，空着的）
  • vacation 假期 （vac + -ation，把事务清空的时光）
  • vanish 消失 （van + -ish，化为空无）
  • avoid 避免 （a- 使 + void，"使对方落空、躲开"）
  • devoid 缺乏的 （de- 完全 + void，"完全空掉"）
🧩 变体家族 vac- vacuum, vacant, vacation
van- vanish, vanity「虚荣（空空如也）」
void- avoid, void「作废」
口语/生活用：Sorry, that seat isn't vacant — my friend is sitting there. 抱歉，那个位子不是空的——我朋友坐着呢。
5pot = power 力量、能力
💡 记法：potential = 还没发挥的"力量"；omnipotent = 什么都能的（全能） 词源：拉丁语 posse「能、有力」，potens「有力的」，源自印欧语 *poti-「主人、有力」 演化：力量 → 有潜力=potential ｜ 强有力的=potent ｜ 全能=omnipotent
  • potential 潜力、可能的 （pot + -ent + -ial，未释放的力量）
  • potent 强有力的 （pot + -ent）
  • omnipotent 全能的 （omni- 全 + potent）
  • possible 可能的 （posse 变体，"能够做到"）
  • potentate 君主、当权者 （pot + -entate，"掌权之人"）
  • power 力量 （posse 经法语变体 poair→power）
口语/生活用：This idea has great potential — we should develop it. 这个想法潜力很大——我们应该好好开发它。
6anthrop = human 人（希腊）
💡 记法：anthropology = 研究"人"的学问；philanthropist = 爱"人"的人（慈善家） 词源：希腊语 anthropos「人类」 演化：人 → 研究人的学问=anthropology ｜ 爱人类=philanthropy ｜ 恨人类=misanthrope
  • anthropology 人类学 （anthrop + -ology 学问）
  • philanthropist 慈善家 （phil 爱 + anthrop + -ist，呼应昨日 phil）
  • misanthrope 厌世者 （mis 恨 + anthrop，"恨人类的人"）
  • anthropoid 类人猿 （anthrop + -oid 似，"像人的"）
  • anthropocentric 人类中心的 （anthrop + centr 中心 + -ic）
  • anthropomorphic 拟人化的 （anthrop + morph 形，赋予人形）
口语/生活用：She's studying anthropology at university. 她在大学读人类学。
7micro = small 小（希腊）
💡 记法：microscope = 看"小"东西的仪器；microbe = "小"生命（微生物） 词源：希腊语 mikros「小的」 演化：小 → 看小的仪器=microscope ｜ 小生命=microbe ｜ 小宇宙=microcosm
  • microscope 显微镜 （micro + scope 看，呼应今日 scope）
  • microbe 微生物 （micro + be 生命，"微小生命"）
  • microwave 微波炉 （micro + wave 波）
  • microchip 微芯片 （micro + chip 片）
  • microphone 麦克风 （micro + phone 声音，把"小"声音放大）
  • microcosm 微观世界 （micro + cosm 世界，呼应明日 cosm）
口语/生活用：Bacteria can only be seen under a microscope. 细菌只有在显微镜下才能看见。

词缀（3 个）

8-hood = state, group 状态、群体（古英语）
💡 记法：childhood = 当"孩子"的那段人生；neighborhood = 住在"附近"的一群人 词源：古英语 -had「状态、性质」，与 -dom、-ship 同为日耳曼来源的状态后缀 演化：古英语 -had → 现代英语 -hood，表人生阶段 / 群体 / 身份
  • childhood 童年 （child + -hood，当孩子的阶段）
  • boyhood 少年时期 （boy + -hood）
  • neighborhood 街区、邻里 （neighbor + -hood，邻居群体）
  • brotherhood 兄弟情谊 （brother + -hood）
  • motherhood 母性、母职 （mother + -hood）
  • livelihood 生计 （lively 活 + -hood，"活命的根本"）
💡 深度辨析：状态后缀 -hood / -dom / -ship -hood（人生阶段/群体，日耳曼）：childhood, neighborhood
-dom（领域/统治，Day 9 学过）：kingdom, freedom
-ship（身份/关系，Day 7 学过）：friendship, leadership
例：childhood（童年阶段）vs kingdom（统治领域）vs friendship（人际状态）
口语/生活用：Childhood memories are often the sweetest. 童年的回忆往往最甜蜜。
9bi- = two 二（拉丁）
💡 记法：bicycle = 两个"轮子"；bilingual = 会"两种"语言的 词源：拉丁语 bi- / bis「二」，源自印欧语 *dwi-「二」（与英语 two、希腊 di- 同源） 演化：二 → 两个轮子=bicycle ｜ 两种语言=bilingual ｜ 双边的=bilateral
  • bicycle 自行车 （bi- + cycle 圆，两个轮子）
  • bilingual 双语的 （bi- + ling 语言 + -ual）
  • biweekly 每两周的 （bi- + weekly，"两周一次"）
  • bilateral 双边的 （bi- + lateral 侧）
  • binary 二进制的 （bi- + -nary，"两态的"，电脑 0/1）
  • bifocals 双光眼镜 （bi- + focal 焦点的）
💡 深度辨析：bi- vs semi- vs di- bi-（拉丁，二）：bicycle, bilingual
semi-（拉丁，半，明日学）：semicircle, semicolon
di-（希腊，二）：dilemma「两难」, dioxide「二氧化物」
经典陷阱：biweekly（每两周一次）vs semiweekly（每周两次）——"二"和"半"完全不同！
口语/生活用：She's bilingual — she speaks English and Chinese fluently. 她会两种语言——英语和中文都很流利。
10anti- = against 反、对抗（希腊）
💡 记法：antibiotic = 对抗"生命"（细菌）的药；antiwar = 反战的 词源：希腊语 anti「对立、反对、代替」 演化：对抗 → 对抗细菌=antibiotic ｜ 反对战争=antiwar ｜ 防止冷冻=antifreeze
  • antibiotic 抗生素 （anti- + bio 生命，"对抗细菌之物"）
  • antisocial 反社会的 （anti- + social）
  • antiwar 反战的 （anti- + war）
  • antibody 抗体 （anti- + body 身体，"对抗入侵之体"）
  • antifreeze 防冻液 （anti- + freeze 冻）
  • anti-aging 抗衰老 （anti- + aging 老化）
💡 深度辨析：anti- vs counter- vs 词根 contra- anti-（希腊）：antibiotic, antisocial
contra- / counter-（拉丁）：contradict「反驳」, counterattack「反击」
例：antibiotic（希腊医学术语）vs counterattack（拉丁军事用语）——anti- 多用于科学/态度，contra- 多用于动作/对立
口语/生活用：The doctor prescribed antibiotics for the infection. 医生为这个感染开了抗生素。
