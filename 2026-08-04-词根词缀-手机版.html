词根词缀每日积累 · Day 1

2026 年 8 月 4 日 ｜ 词根 7 个 · 词缀 3 个 ｜ 附词源与演化

一、词根（7 个）

1spect = 看（look）
💡 记法：眼镜 spectacles 就是"看"的工具 词源：拉丁语 specere「看、观察」，源自古印欧语 *spek-「注视」 演化：向前看 → expect 期待 ｜ 反复看 → respect 尊重 ｜ 向下看 → suspect 怀疑 ｜ 往里看 → inspect 检查
  • expect 期待，预料 （向外看 → 望向未来）
  • respect 尊重 （反复看 → 仰视）
  • suspect 怀疑；嫌疑犯 （向下看 → 心里犯嘀咕）
  • inspect 检查，视察 （往里看）
  • spectator 观众
口语：I expect you to be on time. 我希望你准时到。
2port = 搬运（carry）
💡 记法：护照 passport 就是"过港口"的凭证 词源：拉丁语 portare「搬运、携带」——注意与 portus「港口」是两个不同的词根：airport、passport 里的 port 来自 portus 演化：搬回 → report 报告 ｜ 从下面托住 → support 支持 ｜ 搬到别处 → transport 运输 ｜ 带进去/带出去 → import / export
  • report 报告 （搬回来 → 汇报）
  • support 支持 （从下面托着）
  • transport 运输 （从这里搬到那里）
  • import / export 进口 / 出口
  • portable 便携的
生活用：portable charger 充电宝 ｜ airport 机场（来自 portus「港口」）
3dict = 说（say）
词源：拉丁语 dicere「说、宣告」，源自古印欧语 *deik-「指出、表明」（digit「手指」同源——手指就是用来"指"的） 演化：提前说 → predict 预测 ｜ 对着说 → contradict 反驳 ｜ 一遍遍说 → dictate 口述、支配
  • predict 预测 （提前说）
  • dictionary 词典 （说出来的词）
  • dictate 口述；支配 （"我说了算"）
  • contradict 反驳 （对着说）
口语：Don't dictate to me. 别对我指手画脚。
4cred = 相信（believe）
词源：拉丁语 credere「相信」，最初是「把心放进（某人那里）」——交心 = 信任 演化：交心 → 信任 → credit 信用 ｜ 加 in-（不）→ incredible 难以置信 ｜ 加 -ible → credible 可信的
  • credit 信用；学分；贷款
  • incredible 难以置信的 （口语里 = 超赞）
  • credible 可信的
  • credentials 学历 / 资质证明
生活用：credit card 信用卡（几乎天天见）
5vis / vid = 看（see）
词源：拉丁语 videre「看」（过去分词 visus），源自古印欧语 *weid-「看见、知道」（wise、wit、idea 同源） 演化：再看一遍 → revise 复习 ｜ 看得见 → visible ｜ 看得见的事实 → evidence 证据
  • visit 参观，拜访
  • visible 看得见的
  • vision 视力；愿景
  • revise 复习；修改 （再看一遍）
  • evidence 证据 （看得见的事实）
词组：revise for the exam 复习备考
6tele = 远（far）
词源：希腊语 tēle「远的」 演化：19 世纪起科学新词大量用它构词：远+声 → telephone 电话 ｜ 远+视 → television 电视 ｜ 远+看 → telescope 望远镜；现代又造出 telework、telemedicine
  • telephone 电话 （远方传来的声音）
  • television 电视
  • telescope 望远镜
  • telework / telecommute 远程办公
  • telemedicine 远程医疗
生活用：现在很多人 work from home（在家办公）
7bio = 生命（life）
词源：希腊语 bios「生命」（区别于 zōē「生命力」） 演化：17–19 世纪出现 biology 生物学、biography 传记 → 20 世纪造出 biofuel、biodegradable；如今 bio- 成了环保标识的常见前缀
  • biology 生物学
  • biography 传记 （写一生）
  • biodegradable 可生物降解的
  • biofuel 生物燃料
生活用：biodegradable plastic 可降解塑料（超市购物袋上常见）

二、词缀（3 个）

8re- = 再、又、回（again / back）
词源：拉丁语 re-，源自古印欧语 *wert-「转」，本义「转回去」 演化：转回去 → return 返回、refund 退款 ｜ 转回起点 → recycle 回收、reuse 再利用 ｜ 再看一遍 → review 复习
  • return 返回；归还
  • review 复习；评论 （再看一遍）
  • recycle 回收利用
  • refund 退款 （把钱退回来）
生活用：I'd like a refund. 我要退款。—— 购物退换货最常用的一句！
9-able / -ible = 可…的（able to be）
词源：拉丁语后缀 -abilis / -ibilis「能被…的」，经古法语 -able 进入英语 演化：最初只接拉丁语动词（visible、credible）→ 后来"本土化"可接任何动词：washable、breakable——构词能力极强
  • comfortable 舒服的
  • available 有空的；可获得的
  • reliable 可靠的
  • affordable 买得起的
口语：Are you available tomorrow? 你明天有空吗？—— 几乎天天用
10-less = 无…的（without）
词源：古英语 -lēas「没有…的」，源自 lēas「缺乏、自由」，与 loose、lose 同源 演化：古英语时期就开始大量构词（homeless 早在 12 世纪）→ 现代无线时代又造出 wireless
  • helpless 无助的
  • careless 粗心的
  • useless 没用的
  • wireless 无线的
  • endless 无尽的
生活用：wireless charging 无线充电
