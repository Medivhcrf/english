Day 1（2026-08-04）· 词根 7 个 + 词缀 3 个

  • spect ＝ 看（look）

- 💡 眼镜 spectacles 就是"看"的工具

- 词源：拉丁语 specere「看、观察」，源自古印欧语 *spek-「注视」

- 演化：向前看 → expect 期待 ｜ 反复看 → respect 尊重 ｜ 向下看 → suspect 怀疑 ｜ 往里看 → inspect 检查

- 单词：expect（期待，预料）；respect（尊重）；suspect（怀疑；嫌疑犯）；inspect（检查，视察）；spectator（观众）

- 例句：I expect you to be on time. — 我希望你准时到。

  • port ＝ 搬运（carry）

- 💡 护照 passport 就是"过港口"的凭证

- 词源：拉丁语 portare「搬运、携带」——注意与 portus「港口」是两个不同的词根：airport、passport 里的 port 来自 portus

- 演化：搬回 → report 报告 ｜ 从下面托住 → support 支持 ｜ 搬到别处 → transport 运输 ｜ 带进去/带出去 → import / export

- 单词：report（报告）；support（支持）；transport（运输）；import / export（进口 / 出口）；portable（便携的）

- 例句：portable charger — 充电宝

  • dict ＝ 说（say）

- 词源：拉丁语 dicere「说、宣告」，源自古印欧语 *deik-「指出、表明」（digit「手指」同源——手指就是用来"指"的）

- 演化：提前说 → predict 预测 ｜ 对着说 → contradict 反驳 ｜ 一遍遍说 → dictate 口述、支配

- 单词：predict（预测）；dictionary（词典）；dictate（口述；支配）；contradict（反驳）

- 例句：Don't dictate to me. — 别对我指手画脚。

  • cred ＝ 相信（believe）

- 词源：拉丁语 credere「相信」，最初是「把心放进（某人那里）」——交心 = 信任

- 演化：交心 → 信任 → credit 信用 ｜ 加 in-（不）→ incredible 难以置信 ｜ 加 -ible → credible 可信的

- 单词：credit（信用；学分；贷款）；incredible（难以置信的）；credible（可信的）；credentials（学历 / 资质证明）

- 例句：credit card — 信用卡（几乎天天见）

  • vis / vid ＝ 看（see）

- 词源：拉丁语 videre「看」（过去分词 visus），源自古印欧语 *weid-「看见、知道」（wise、wit、idea 同源）

- 演化：再看一遍 → revise 复习 ｜ 看得见 → visible ｜ 看得见的事实 → evidence 证据

- 单词：visit（参观，拜访）；visible（看得见的）；vision（视力；愿景）；revise（复习；修改）；evidence（证据）

- 例句：revise for the exam — 复习备考

  • tele ＝ 远（far）

- 词源：希腊语 tēle「远的」

- 演化：19 世纪起科学新词大量用它构词：远+声 → telephone 电话 ｜ 远+视 → television 电视 ｜ 远+看 → telescope 望远镜；现代又造出 telework、telemedicine

- 单词：telephone（电话）；television（电视）；telescope（望远镜）；telework / telecommute（远程办公）；telemedicine（远程医疗）

- 例句：work from home — （在家办公）

  • bio ＝ 生命（life）

- 词源：希腊语 bios「生命」（区别于 zōē「生命力」）

- 演化：17–19 世纪出现 biology 生物学、biography 传记 → 20 世纪造出 biofuel、biodegradable；如今 bio- 成了环保标识的常见前缀

- 单词：biology（生物学）；biography（传记）；biodegradable（可生物降解的）；biofuel（生物燃料）

- 例句：biodegradable plastic — 可降解塑料（超市购物袋上常见）

  • re- 词缀 ＝ 再、又、回（again / back）

- 词源：拉丁语 re-，源自古印欧语 *wert-「转」，本义「转回去」

- 演化：转回去 → return 返回、refund 退款 ｜ 转回起点 → recycle 回收、reuse 再利用 ｜ 再看一遍 → review 复习

- 单词：return（返回；归还）；review（复习；评论）；recycle（回收利用）；refund（退款）

- 例句：I'd like a refund. — 我要退款。—— 购物退换货最常用的一句！

  • -able / -ible 词缀 ＝ 可…的（able to be）

- 词源：拉丁语后缀 -abilis / -ibilis「能被…的」，经古法语 -able 进入英语

- 演化：最初只接拉丁语动词（visible、credible）→ 后来"本土化"可接任何动词：washable、breakable——构词能力极强

- 单词：comfortable（舒服的）；available（有空的；可获得的）；reliable（可靠的）；affordable（买得起的）

- 例句：Are you available tomorrow? — 你明天有空吗？—— 几乎天天用

  • -less 词缀 ＝ 无…的（without）

- 词源：古英语 -lēas「没有…的」，源自 lēas「缺乏、自由」，与 loose、lose 同源

- 演化：古英语时期就开始大量构词（homeless 早在 12 世纪）→ 现代无线时代又造出 wireless

- 单词：helpless（无助的）；careless（粗心的）；useless（没用的）；wireless（无线的）；endless（无尽的）

- 例句：wireless charging — 无线充电

Day 2（2026-08-05）· 词根 7 个 + 词缀 3 个

  • fac / fact / fect ＝ do, make（做，制作）【拉丁】

- 💡 factory「工厂」里工人整天在做(fac)东西，fac 就是"做"。

- 词源：拉丁语 facere「做、制作」，分词形式 factum「做出来的事」；源自印欧语 *dhe-「放、放置」，英语 do、deed、希腊语 theme 同源。

- 演化：本义「做」 → factor 做的人/因素、manufacture 亲手制作 ｜ 「做出来的东西」 → fact 事实、factory 工厂、effect 效果 ｜ 「外力作用于」 → affect 影响 ｜ 「完全做好」 → perfect 完美

- 单词：fact（事实；真相）；factory（工厂）；manufacture（制造，生产）；affect（影响；使感动）；effect（效果，影响）；perfect（完美的）

- 例句：The factory manufactures thousands of phones a day. — 这家工厂每天生产数千部手机。

  • scrib / script ＝ write（写）【拉丁】

- 💡 scribere 原指在蜡板上用尖笔"刻写"，scrib 就是"刻着写"。

- 词源：拉丁语 scribere「写」，过去分词 scriptus；源自印欧语 *skribh-「划、刻」（最初是用尖笔在蜡板上刻画字形）。

- 演化：本义「刻写」 → describe 描下来=描述、transcript 转写 ｜ 「预先写(处方)」 → prescribe 开处方 ｜ 「在下面签名」 → subscribe 订阅、签字同意

- 单词：describe（描述）；subscribe（订阅；赞同）；manuscript（手稿；原稿）；prescribe（开处方；规定）；transcript（成绩单；文字记录）；script（剧本；脚本）

- 例句：I subscribed to the streaming service to watch the new show. — 我订阅了流媒体服务来追那部新剧。

  • mit / miss ＝ send, let go（送，放出）【拉丁】

- 💡 missile「导弹」是"被送出去的东西"，mit/miss 就是"送"。

- 词源：拉丁语 mittere「送、发出」，过去分词 missus；印欧语来源一般归于 *meith-「交换、送」。同源词 mission、message。

- 演化：本义「送」 → transmit 传送、emit 发出 ｜ 「被送出去的任务」 → mission 使命 ｜ 「把…送走」 → dismiss 解散 ｜ 「放进来」 → admit 承认/准入

- 单词：mission（使命；任务）；transmit（传送；发射）；submit（提交；屈服）；admit（承认；准许进入）；dismiss（解散；不予理会）；permission（许可）

- 例句：You have to submit your assignment before midnight. — 你必须在午夜前提交作业。

  • struct ＝ build（建造）【拉丁】

- 💡 structure「结构」里就是 struct，凡是"搭起来"的东西都带它。

- 词源：拉丁语 struere「堆叠、建造」，过去分词 structus；源自印欧语 *stere-「铺开、摊开」（英语 streak、straw 同源）。

- 演化：本义「堆叠建造」 → construct 一起搭建、structure 结构 ｜ 「往头脑里搭建」 → instruct 教导 ｜ 「拆掉搭建」 → destroy 摧毁 ｜ 「挡住建造」 → obstruct 妨碍

- 单词：construct（建造；构建）；structure（结构；建筑物）；instruct（教导；指示）；destroy（摧毁）；obstruct（妨碍，阻挡）；infrastructure（基础设施）

- 例句：They're constructing a new subway line near my place. — 他们正在我家附近修一条新地铁线。

  • voc / vok ＝ call, voice（喊，声音）【拉丁】

- 💡 voice「声音」和 vocab 都是 voc 变体，"喊"出来的。
